# Standards sources and implementation status

**Planning date and source access date: 2026-10-04. Target school year: 2026-27.**
All source entries record research on that date; the register distinguishes
directly inspected text, indexed document references and failed retrievals.
These are concise paraphrases, not reproductions of standards. Source years are
edition labels; they are not necessarily adoption or implementation years.

## Classification and claim limits

- **Official standard:** Minnesota's adopted subject standards. Their public-school
  implementation dates are a reference for this Catholic school's planning, not
  a finding that every public-school accountability requirement applies here.
- **Official guidance/teaching:** MDE implementation guidance; Archdiocesan
  guidance or policy; Vatican/USCCB teaching. These are not interchangeable
  with numbered academic benchmarks.
- **National standard/framework:** CSTA, NGSS, National Core Arts Standards and
  ISTE. Use selectively; no Minnesota or Archdiocesan adoption is inferred.
- **Local program standard:** The eighteen `CST-*` competencies in
  [Local Standards](Local_Standards.md). **Not MDE-approved, not
  Archdiocese-approved, and not a complete subject curriculum.**

Source verification does not establish lesson alignment. No external benchmark
number is assigned to a lesson by this research. A claim requires the exact
edition, applicable grade, verified benchmark, matching student task and
assessment evidence. A topic resemblance or a local code is insufficient.
**All generated external-alignment fields remain VERIFICATION REQUIRED** until
that benchmark + lesson + individual assessment/evidence mapping is reviewed.
A verified source, implementation date or local-code entry does not remove this
hold.
