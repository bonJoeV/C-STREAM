## VOCABULARY / TEACHER BACKGROUND

**Circumference:** distance around. **Diameter:** across center.
**Ratio:** division comparison. **Uncertainty:** limits in measurement.
Pi is irrational (decimal neither terminates nor eventually repeats); that is
a mathematical fact, not evidence that a physical measurement has infinite
precision. **Common misconception:** measure radius instead of diameter.
**If asked, "Did we discover exact pi?"** No; our tool estimates are rounded.
Worked fictional C/D: 18.9/6 = 3.15; 25.1/8 = 3.1375;
31.4/10 = 3.14. All compare to about 3.14, not expected actual values.

## EXACT LESSON SEQUENCE

1. **0-4 (4 min):** Ask "Why might every circle give a similar ratio?" Discuss honest estimates.
2. **4-11 (7 min):** Demonstrate string circumference, straight centered diameter and equal-unit division.
3. **11-25 (14 min):** Rotate wrapper/measurer/recorder across three lids; each pupil measures one and records all three values/ratios.
4. **25-35 (10 min):** Repeat one C/D pair; compare original/repeat and possible string gaps/center error. Keep both, no data correction to 3.14.
5. **35-41 (6 min):** Each student independently calculates one ratio with units, explains the three-object pattern and uncertainty, and distinguishes evidence from a philosophical view of mathematics.
6. **41-45 (4 min):** Coil string, count lids/tools, save tables and tidy.

## QUESTIONS TO ASK STUDENTS / WHAT SUCCESS LOOKS LIKE

"Did you cross the center? Would a stretched string increase C? Why not erase
an unexpected ratio?" Each has three measured pairs, one checked division,
repeat/uncertainty and claim distinction. 1 unsupported; 2 prompted;
3 independent; 4 explains error direction; NE for missing measurement.

## IF THINGS GO WRONG / SAFETY

Ratio near 6 -> check radius/diameter. No lids -> adult-drawn circles measured
as drawings, not manufactured objects. No calculator -> use worked long
division scaffold. No string around bodies, tasting, sharp cans, rolling
objects or device uploads. Stop/report unsafe handling.

## SUPPORT / CHALLENGE / INDOOR FALLBACK

Grade 5/support: center-marked lid, ruler guide, calculator/scribed reasoning.
Grade 6/challenge: compare absolute difference from 3.14 and explain precision;
more measurements need not get closer every time. Indoor tabletop primary.
