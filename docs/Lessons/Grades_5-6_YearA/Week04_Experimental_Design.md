# Week 4: Experimental Design

## LESSON AT A GLANCE

| Field | Reference |
|---|---|
| Grade / schedule / rotation / unit | 5-6 / Weekly / A / Investigation |
| Time | 1 meeting of 45 minutes |
| Objective / big idea | I can collect six rolling-distance values, identify changed/measured factors and two controls, and compare conditions honestly. |
| Why / domains | Fair comparisons inform decisions in science and daily life; S, M, C. |
| Catholic connection | Pursuit of truth requires keeping surprising results, not changing data to fit a prediction. |
| Local standards | CST-S2: repeatable controlled test; CST-M2: table/comparison; CST-C1: honest limit. Official benchmarks VERIFICATION REQUIRED. |

## BEFORE CLASS

1. Review accommodations/emergency contact. Seat 4/5/7/9 teams of at most three.
2. Put a 30 cm cardboard ramp on one versus two identical 3 cm-high books; heights 3/6 cm, never over 15 cm. Ramp ends inside a 60 cm-long tray.
3. Adult trials both heights. If ball reaches tray end, lengthen the runout safely or reduce both heights before class; collisions invalidate stopping-distance values.
4. Mark release point at ramp top and ruler zero at ramp end. Copy table columns Height cm / Trial 1 / Trial 2 / Trial 3 / Notes. Rotate releaser/measurer/recorder every trial.

## VOCABULARY / TEACHER BACKGROUND

**Independent variable:** factor changed (height). **Dependent variable:**
measured result (stopping distance). **Control:** condition kept consistent.
**Trial:** one run. Gravity accelerates the ball; surface friction/rolling
resistance helps stop it. This test cannot isolate all physical mechanisms.
**Common misconception:** gravity's magnitude increases when the ramp steepens.
The same ball's gravitational force is essentially unchanged; the component
along the slope changes. **If asked, "Must my prediction be right?"** No;
report what happened. No hot-water or projectile alternative.

**Worked fictional example, not expected results:** at 3 cm, distances
12/14/13 cm; at 6 cm, 19/21/20 cm. Totals 39/60 cm; means 13/20 cm;
mean difference 7 cm. Grade 5 compares ranges or trial values; teach the
mean calculation before Grade 6 uses it.

## EXACT LESSON SEQUENCE

1. **0-4 (4 min):** Ask "Does release height change stopping distance?" Predict privately; brief truth/service reflection.
2. **4-11 (7 min):** Demonstrate release without push, measure from ramp end, keep ball/ramp/surface/release point unchanged. Show worked table and safety.
3. **11-25 (14 min):** Teams run three trials at each height. Each student releases and measures at least one run, copies six actual values with cm; record collisions as invalid with reason and repeat.
4. **25-35 (10 min):** Compare conditions; calculate using the scaffold, not the fictional answer. Exchange protocols: can a peer name height, distance and two controls? Note variability and confounds.
5. **35-41 (6 min):** Each independently names IV/DV/two controls, cites two values or means and one limitation. Teacher gathers tables/exit evidence, not only group success.
6. **41-45 (4 min):** Retrieve balls, stack books, remove tape, store ramps dry, save records.

## QUESTIONS TO ASK STUDENTS / WHAT SUCCESS LOOKS LIKE

"What stayed the same? Did the ball hit the wall? Could a push explain this?"
Success: six valid recorded values with units, accurate variables/two controls,
one numerical comparison and an honest limit. 1 unsupported; 2 prompted;
3 independent; 4 explains a confound; NE for missing evidence.

## IF THINGS GO WRONG / SAFETY

Unstable support -> stop and adult resets. Results overlap -> report overlap,
not guaranteed height effect. No long tray/ball -> analyze the explicitly
fictional example and write a protocol; physical investigation deferred.
No launches, tasting, chemicals or students in rolling paths. Keep hands away
until stopped; stop/report injury or damaged kit.

## SUPPORT / CHALLENGE / INDOOR FALLBACK

Grade 5/support: ruler guide, prewritten table, oral explanation/scribing.
Grade 6/challenge: compare means/ranges and justify a further controlled test.
Entire lesson indoors; no winter alternative equipment needed.

## CLEANUP / FAMILY NEWSLETTER

Count kit pieces, save raw values, record incomplete trials and replenish tape.
**Explored:** fair tests. **Did:** six safe rolls and a comparison. **Learned:**
variation is evidence. **Catholic connection:** honest inquiry. **Ask:**
"What did you keep constant?" No routine homework or home experiment required.

## TEACHER ARTIFACTS

Use this operational set for the six-trial 3 cm/6 cm ramp investigation.

### Student material and evidence

- **Printable/no-print prompt:** Table **height cm | trials 1-3 distance cm | invalid/reason | comparison** plus “IV ___; DV ___; controls ___ and ___; cite two values/means; limitation ___.” Board-copy is identical.
- **Expected evidence, worked and finished examples:** IV = 3/6 cm ramp height; DV = stopping distance from ramp end; valid controls include ball, ramp, surface, release point and no push. Work only the labeled fictional 12/14/13 and 19/21/20 cm example (means 13/20, difference 7). Finished evidence is six actual valid values with units and honest overlap/confound; a finished build is **N/A** because the ramp is apparatus, not a designed product.

### Teacher display and discussion

- **Visual example:** Display a side-by-side **3 cm ramp / 6 cm ramp** diagram with the same soft ball, release line, tray surface and ruler zero at the ramp end. Beside it, show the fictional rows **12, 14, 13 cm** and **19, 21, 20 cm**, labeling these numbers “worked example—not class data.”
- **Board setup/discussion:** Draw both ramp heights, ruler zero at ramp end, six-cell table and **same: ball/ramp/surface/release | changed: height | measured: stop cm**. Ask what stayed same, whether wall contact invalidates the value, and whether a push could explain it. Accept overlap as overlap. Misconceptions: steeper ramp does not increase gravity’s magnitude; a wrong prediction is not failed science; collision distance is not a stopping distance.

### Kit, closure, and continuation

- **Kit/reference/reset:** Exact MATERIALS only: paper/pencil per pupil; ramp, soft ball, tray, ruler, table and two identical books per team; 0.2 m tape; teacher board/clock/roster. **Kit label:** **RAMP INVESTIGATION—W4—3/6 CM, 3 TRIALS EACH—BALL/TRAY/RULER**. Remove tape, stack two books, nest dry tray/ramp, count ball/ruler, and file raw tables.
- **Unfinished work:** Cross-hatch only missing trial cells and write the current unchanged setup; rerun those trials before comparing. Preserve invalid collision rows and never fill a team value from the fictional example.

### Interpretation and reteach

- **Specific misconceptions:** “The 6 cm ramp won” substitutes a verdict for the six measured distances; changing the ball or pushing at release confounds ramp height; measuring from the table edge instead of the ramp end shifts every result; a wall collision is an invalid trial to retain and rerun, not a learner failure.
- **Annotated exemplar / Common error interpretation / reteach:** Underline “height,” box six cm values, star ball/release controls, and circle “6 cm values were usually longer, but overlap/other factors limit cause.” A single extreme may be valid variability; equal repeated values are not automatically copied. Radius-from-wrong-zero indicates method error. Reteach one no-push release and zero alignment, then have the pupil name changed/measured/kept factors before one supervised repeat.
