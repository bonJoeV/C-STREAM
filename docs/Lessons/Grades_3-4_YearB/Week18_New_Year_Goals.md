# Week 18: New Year Goals

## Lesson at a glance

Grades 3-4; Weekly B; Reflection; **one 40-minute meeting**.
**Objective:** select one evidence-recording goal, practice twice and compare
checked features to decide a next step. **Why:** purposeful effort needs
observable follow-through, not four ambitious promises.
Catholic/CST-C3 stewardship of work; CST-M2 dated tracker; CST-M3 count/change.
Official alignment **VERIFICATION REQUIRED**. Technology **None**;
introductory. Prep 10; cleanup 5 included. No five-project target, required
family tracker or rating spiritual growth.

## Before class / supplies

Per pupil: portfolio, two sheets/pencil. Teacher board/timer; source on board
**simulated flight cm data: first 40/50/40; second 50/60/50**.
Goal example: "By minute 30 I will copy a three-trial table with title, cm unit
and all three readings correct." Three features, checked 0-3.
Missing portfolio uses supplied data, not invented first-semester history.
Teams <=3 confer at desks (4/5/7/9); no team-specific hardware.

## SAFETY

**Background, vocabulary, and troubleshooting:**

SMART = specific/measurable/achievable/relevant/time-bound; tracker = actual
record; action = practice step; evidence = observed result.
**Misconception:** meeting a goal once proves permanent mastery.
**If asked "Does prayer guarantee success?"** Prayer accompanies effort, not
a performance guarantee or measure of a child's worth.
Desk paper only, no private faith/service/family disclosure or peer rankings.
Report missing records; indoor primary.

## Meeting 1: exactly 40 minutes

1. **0-4:** Optional prayer for patient work; "Which saved task needs a clearer
   record?" View portfolio briefly, no forced personal confession.
2. **4-10:** Model one SMART goal and tracker `attempt/time | 0-3 | next action`.
3. **10-20:** Write goal/relevance/two actions; copy first simulated table, peer
   checks title/unit/values, each records actual feature count.
4. **20-30:** Apply action to missing feature, copy second table; recheck/record.
5. **30-35:** Each child compares counts, identifies action from evidence and states
   simulation label/limit. "What changed in your practice?"
6. **35-40:** Date/file tracker, return portfolios/pencils, clear. Teacher
   schedules optional next-class check without hiding extra required meetings.

## What success looks like

Meets: one measurable goal, two real check counts, accurate comparison and
next action tied to result. Grade 3/support: goal stem/dictation/three boxes.
Grade 4/challenge: explain later transfer check needed. No improvement: record
same count and propose support, not invented progress. Too ambitious: reduce
to three table features today. Early finish: new data/table, same criteria.

**Family:** We practiced and tracked one goal. Ask, "What did evidence tell you
to try next?" Optional conversation, not compulsory home monitoring.

## Teacher artifact pack

- **Student goal/tracker (print/no-print):** Sheet 1 fields: `Name/date`, `Portfolio artifact noticed OR supplied practice data`, `By minute 30 I will ___`, checks for `specific`, `measurable`, `achievable`, `relevant`, `time-bound`, and `Why this recording skill matters`. Sheet 2: `Attempt | time | title present? | cm unit present? | all 3 values correct? | feature count 0-3 | next action`, with rows 1 and 2. No-print: copy the same goal stem and tracker onto two plain sheets.
- **Expected evidence and answers:** A valid goal names the observable table features and a time, rather than “be better at science.” For supplied data, attempt 1 must reproduce `40, 50, 40 cm`; attempt 2 `50, 60, 50 cm`. Counts reflect title/unit/values, so any honest 0-3 is acceptable. The next action targets a missing feature, such as `circle cm before copying` or `check all three values against the board`.
- **Worked completed example:** `Goal: By minute 30 I will copy a three-trial flight table with a title, cm unit, and all values correct. Attempt 1 at 10:18: title yes, unit no, values yes = 2/3. Action: write cm in every column heading first. Attempt 2 at 10:27: 3/3. Next check: use the same checklist on a new dataset next class.` Annotate each SMART component and note that one successful attempt does not prove permanent mastery.
- **Board setup:** Display both simulated datasets, a three-box checklist `TITLE | UNIT | VALUES`, and the tracker model. Add `observed today / not yet known` columns so pupils can distinguish present practice from a future transfer claim.
- **Discussion questions:** “What makes this goal measurable?” (three named features and a count), “If the count stays 2, is the record dishonest?” (no; it identifies needed support), “Does one 3/3 prove mastery forever?” (no), and “What should the next action address?” (the missing feature). Correct goals about worth, prayer outcomes, or several unrelated projects.
- **Kit contents:** Per pupil: `1 portfolio, 2 plain-paper sheets, 1 pencil`; no team hardware.
- **Kit label:** Kit label: mark the return tray `W18 | GOAL TRACKERS | CONFIDENTIAL CLASS WORK`; use only the school’s existing pupil/class identifier on each private folder.
- **Cleanup and reset:** Label the return tray `W18 | GOAL TRACKERS | CONFIDENTIAL CLASS WORK` and each folder with the existing pupil/class identifier under school practice, not new personal data. Return portfolios in roster order, clip both dated sheets together, count pencils, and leave no artifact on public display without permission.
- **Unfinished work:** Mark one status on the clipped tracker: `goal wording`, `attempt 1`, `attempt 2`, or `comparison/next action`. Provide the supplied dataset at the next in-class completion opportunity; do not require family monitoring or invent an attempt completed outside observation.
- **Annotated exemplar:** Annotated exemplar: mark the completed goal’s named title/unit/values criteria, attempt 1 score `2/3`, missing `cm`, corrective action, attempt 2 score `3/3`, and the stated need for a later transfer check.
- **Safety and supervision:** Physical severity **minor** and likelihood **rare** for seated paper work; privacy/emotional severity **moderate** if personal goals or records are exposed, with likelihood **unlikely** when portfolios remain private. Adult ratio **1:25 maximum**, teams at most 3 for feedback, and no forced disclosure of faith, family, or personal difficulty. **SDS: not applicable**.
- **Print accessibility:** Use 14-point text, large yes/no checkboxes, one tracker row per line, and plain-language SMART prompts. Offer read-aloud, dictated goal, scribing, symbols for title/unit/values, or a reduced three-feature template. Verify a grayscale print has clear row boundaries and enough space for three two-digit values plus units.
- **Student material:** Student material: give each pupil the two-sheet goal/tracker set with the SMART checks, two supplied-data attempts, title/unit/values feature counts, next actions, and one pencil.
- **Visual example:** Visual example: display both simulated flight datasets, the `TITLE | UNIT | VALUES` checklist, and `observed today | not yet known` columns beside the completed 2/3-to-3/3 tracker.
- **Common error:** Common error: a vague `I will improve`, an inaccurate 3/3, or a portfolio claim without an artifact is not evidence of the stated goal; annotate the missing criterion and use the supplied practice data.
- **Reteach:** Reteach: jointly rewrite one vague goal as `observable action + title/unit/values checks + minute 30`, model checking one table feature at a time, and record the honest feature count before selecting the next action.
- **Print/accessibility check:** Print/accessibility check: print the black-and-white goal and tracker sheets at 100% with 14-point text, large yes/no boxes, one attempt per row, and enough space for two-digit values, units, drawing, or oral dictation.
