# Session 11: Lenten Service

## Lesson at a glance

Grades 3-4; Bi-Weekly B; Service design; **one 40-minute meeting**.
**Objective:** respond to a teacher-approved classroom need, test a two-step
help card, revise and deliver it for actual use.
**Why:** Lenten charity can involve a modest completed service, not invented
community benefit. Catholic/CST-C2 dignity/listening; CST-E1 user criterion;
CST-E2 actual retest; CST-E3 qualified recommendation.
Official alignment **VERIFICATION REQUIRED**. Technology **None**;
introductory. Prep 10; cleanup 5. No personal sacrifice/donation assessment.

## Before class and exact supplies

Approve need: "Shared markers need caps and a return place after drawing."
Teams <=3 (4/5/7/9): two cardstock cards/two actual classroom markers.
Each pupil paper/pencil. The teacher demo uses two actual classroom markers,
a completed two-step card, the board and timer. Confirm cards can
be used at tables; if not, fictional prototype/handover not completed explicitly.
Paper-only external service later requires adult consent; no unverified exact
Works-of-Mercy recital, food distribution or private family circumstances.

|---|---:|---:|---:|---:|
| Cards; markers (2/team each) | 8 | 10 | 14 | 18 |
| Paper; pencils (1/pupil each) | 10 | 15 | 20 | 25 |

## Vocabulary/background/SAFETY

Need = stated task difficulty; criterion = success; service = useful action;
handover = actual transfer. **Misconception:** promise equals completed action.
**If asked "Did we help every lonely person?"** No; we tested one classroom
routine. Charity respects what people request and their privacy.
Desk marker/paper only; no medical/food/prisoner visits, compelled hardships,
private names or unapproved delivery. Stop/report damaged markers; indoor primary.

## Meeting 1: exactly 40 minutes

1. **0-4:** Optional Lenten service prayer; read actual teacher request.
2. **4-9:** Criterion user names/does both steps from card within ten seconds,
   twice; no coaching. Limit two cards/word AND symbol.
3. **9-21:** Each sketches response, team makes two-step cap/return card.
4. **21-30:** Neighbor performs twice with actual markers, count correct actions
   0-2; revise on card 2/repeat twice.
5. **30-35:** Each child explains need, four counts, change/limit; teacher logs
   accepted handover or not yet, not inferred community impact.
6. **35-40:** Use cards to cap/return real markers, store approved cards,
   file dated evidence/clear.

## Success/access/troubleshooting

Meets: user criterion, actual before/after, justified recommendation.
Completed classroom service separately requires accepted card/use.
Grade 3/support: two numbered pictures/scribing. Grade 4/challenge:
privacy/access tradeoff and what longer-term effectiveness measure is needed.
User confused: simplify one symbol; do not coach test. Missing markers:
paper model actions, label physical/user-use outcome not observed.
Early finish: new user, equal test, no bigger unsupervised service promise.

**Family:** We completed a small approved classroom service. Ask, "What did
the user test show?" Use prototype wording if handover wasn't approved.

## Teacher artifact pack (lesson-specific release checklist)

- **Student material (print/no-print):** Print one **Marker Care Service: design/test/handover** sheet per pupil and two cardstock card frames per team. The evidence sheet must say `Approved need: Shared markers need caps and a return place after drawing`, `Criterion: without coaching, a user names and does both steps within 10 seconds`, `My Step 1 words + symbol ____`, `My Step 2 words + symbol ____`, `Card 1 test A __/2`, `Card 1 test B __/2`, `What confused the user ____`, `Card 2 change ____`, `Card 2 test A __/2`, `Card 2 test B __/2`, `Recommendation and limit ____`, and teacher-only boxes `Accepted for classroom use / Not yet accepted` and `Actually used to cap/return markers / Not yet used`. With no printer, copy those exact labels to the board; pupils quarter a plain sheet for the four scores and make the two release cards from supplied cardstock. Adult scribing and pointing to 0, 1, or 2 are valid access routes.
- **Evidence and answer guidance:** Look for an individual sketch, a team card containing exactly two ordered actions with a word and symbol for each (`1. CAP` plus a cap picture; `2. RETURN` plus an arrow to the marked place), two uncoached trials of Card 1, a documented single clarity change, and two equal-condition trials of Card 2. Each score is the number of correct actions, 0-2--not a rating of kindness. Accept a recommendation such as `use Card 2 because the user completed 2/2 twice after we enlarged the return arrow; it only shows this routine worked in four short tests`. Completed service requires both the teacher's accepted handover and actual card use during the closing marker reset.
- **Worked example and finished example:** On Card 1 show a small cap icon and the words `Put away markers`; record `1/2, 1/2--user capped each marker but did not know where to return it`. On Card 2 write `1 CAP` beside a large cap-on-tip drawing and `2 RETURN` beside an arrow to a box labeled `MARKERS`; record `2/2, 2/2`, change `named the return place and enlarged the arrow`, recommendation `release Card 2 for this table`. Finish the teacher boxes with `Accepted` and, only after the class reset, `Actually used`. Annotate that no result demonstrates wider community impact.
- **Visual example and board setup:** Place two real classroom markers and their approved return container at the demonstration table. On the board write the fixed need and a flow line `teacher request → two-step card → user test twice → one revision → same test twice → handover/use`. Add a four-cell score table headed `C1-A / C1-B / C2-A / C2-B`, a visible 10-second timer, and a `NO COACHING DURING TEST` sign. Show word-and-symbol size at normal viewing distance, not only enlarged under a document camera.
- **Discussion with acceptable response, and misconception:** Ask `Why must the need come from the teacher?` (service responds to a real requested need and stays safe); `What earns one point?` (one of the two actions completed correctly without prompting); `Can the designer explain the card during a trial?` (no, that would hide a clarity problem); `What changed between fair before/after tests?` (only the card's selected word/symbol feature); `When is the service complete?` (after accepted handover and real cap/return use); and `What may we honestly claim?` (the tested routine result, not that every person or classroom was helped). Address the misconception that a promise, attractive card, or large charitable claim equals delivered service.
- **Kit contents, kit label, cleanup and reset:** Kit label: **S11 LENTEN SERVICE--TEAM __--2 CARDSTOCK / 2 MARKERS / EVIDENCE RECORDS**. In each team folder place exactly two cardstock cards and two actual classroom markers; issue one plain planning sheet and pencil per pupil. The teacher station holds the timer, accepted-marker return place, and handover roster--there are no role cards, stamps, labels, or moving/cleaning supplies. On reset, pupils use only an accepted card to cap the two markers and return them; the teacher counts 2 cards and 2 markers per team, separates the released card from Card 1, logs actual use, and restores unaccepted cards to the evidence folder rather than displaying them as completed service.
- **Unfinished work:** Date and retain the two cards with one status strip: `DESIGN ONLY`, `CARD 1 TESTED`, `REVISION NOT RETESTED`, `AWAITING HANDOVER`, or `ACCEPTED--USE NOT YET OBSERVED`. Do not fill missing counts, coach a rushed trial, or mark service complete from intention. Resume with the next named stage using the same two markers and criterion; if markers are unavailable, label paper-mode action evidence **physical/user-use outcome not observed**.
- **Annotated exemplar, common error and reteach:** Mark the exemplar at `real stated need`, `two separate readable steps`, `four raw 0-2 scores`, `one traceable revision`, `qualified recommendation`, and `handover/use status`. Scores that improve while the designer coached indicate an invalid test, so repeat silently; four identical blank/2 scores with no observed record require the observation procedure to be repeated; a card saying only `be responsible` has no performable steps, so convert it to verb + object (`cap marker`); a claim `we helped everyone` needs narrowing to `one classroom marker routine`. Use corrective practice by silently following an intentionally ambiguous card, asking pupils which missing word or symbol prevented Step 2.
- **Safety classification:** **Severity: low; likelihood: unlikely.** Adult ratio: **1 adult for up to 15 pupils during tests and actual marker reset**; run additional teams in a second supervised wave. Only the stated desk-level marker task is authorized: no private names or family circumstances, outside delivery, food, cleaning, lifting, heights, donations, or contact with external recipients. **Commercial-product hold:** Used markers. Enter the exact manufacturer/product in [Safety Data Sheet Register](../../../Review/Safety_Data_Sheet_Register.csv). Keep each listed product on **HOLD** until school approval and SDS applicability are resolved; do not infer a brand or claim SDS N/A.
- **Print/accessibility check:** Set the record in 16-point or larger text with numbered boxes, generous spacing, black-on-white contrast, and symbols paired with verbs. Make the actual service card readable at the table from a seated position; do not encode the sequence by color alone. Offer pre-drawn cap/arrow symbols, reduced writing, oral explanation, scribing, motor support for drawing, and repeated user testing with a reader who can access the chosen print/symbol format.
- **Technology disposition:** No technology artifact applies; evidence is the listed physical work and paper records.
