# Session 16: Makey Makey

## Lesson at a glance

Grades 3-4; Bi-Weekly B; Interactive tools; **one 40-minute meeting**.
**Objective:** test two dry physical inputs mapped to notes, compose a four-beat
pattern and revise the interface after repeated tests.
**Why:** real conductivity/input events enable musical interaction that paper
cannot demonstrate. Catholic/CST-C2 accessible non-body-contact turn;
CST-T1 input-key-note trace; CST-E1 correct-note criterion; CST-E2 retest;
CST-A2 intentional rhythm composition. Official alignment **VERIFICATION
REQUIRED**. Technology **Required**, actual board/computer mandatory;
developing. Prep 25 after model/software verification; installation/loans extra;
cleanup 5.

## Before class and exact supplies

Obtain matching manufacturer instructions via
[Makey Makey](https://www.makeymakey.com/pages/how-to) and in-box model guide.
Landing page alone is **not** a safety manual. Record actual board/age/USB/input/
EARTH closure approval. Pretest **no-body-contact** closure method: insulated
lead from EARTH to a dry foil contact/probe, touch that contact to separate
input pads only if documented/approved. Otherwise paper fallback, no guessed
electrical connection. Teacher handles plugs/disconnects before wiring changes.

Scratch 3 private/offline, add **Music extension**, pretest space/left-arrow:

```text
when [space] key pressed
play note (60) for (1) beats

when [left arrow] key pressed
play note (64) for (1) beats
```

Select no simultaneous inputs, default tempo constant. Save/reopen sample;
two physical closures must match the two key/note events twice. No online piano,
food, wet inputs or required EARTH holding.
Teams <=3 (4/5/7/9): board/computer/manufacturer USB cable/cardstock base,
**three insulated leads**, **three 10 cm foil squares** (two pads/one contact).
Each pupil receives two sheets/pencil. The teacher demo uses the approved
Makey Makey board, compatible school computer, manufacturer USB cable, three
insulated leads, three foil squares, cardstock base, board and timer.
Hardware reusable; foil consumable, label pads with pencil words/symbols.

## Vocabulary/background/SAFETY

Conductive = permits charge flow; input = closure; event = key signal; beat =
steady pulse. **Misconception:** any object conducts sufficiently.
**If asked "Does foil make the music?"** Board sends input; software produces
note. Holding an input may repeat; distinct closures count as tests.
Approved board/USB only, no external battery/mains experiments, modifications,
wet materials or person-to-person circuit. Low volume/silent visual alternative
available. Warm/damaged/failed -> disconnect by adult, OUT OF SERVICE/report.
Dry indoor stations.

## Meeting 1: exactly 40 minutes

1. **0-4:** "How can an interface include people without required body contact?"
2. **4-10:** Demo approved closure, space/left mapping and stop/isolation rules.
3. **10-22:** Adult checks setup; each pupil operates both pads twice, records
   input/key/note. Waiting peers predict and notate four-beat pattern.
4. **22-30:** Compose/perform four distinct beats; peer identifies pad sequence,
   revise pad label/layout, repeat both-input tests and pattern.
5. **30-35:** Each child explains trace, test-backed interface revision and purposeful
   rhythmic choice; log operation, not merely watching.
6. **35-40:** Adult disconnects USB/counts leads/boards; dry foil removed,
   save local project/dated notation, return devices.

## Success/access/troubleshooting

Meets: two verified physical inputs/two cycles, correct trace and deliberate
musical/interface revision. Grade 3/support: two-pad template/scribing/motor
assistance. Grade 4/challenge: accessibility-versus-pad-spacing tradeoff.
No response: isolate, check matching input/EARTH/USB/software, no extra power.
Fewer stations: only teacher-preflighted wave capacity; otherwise paper
pad/event/note cards at same times, rhythm/system reasoning only,
**conductivity/device operation not observed**. No Music extension -> keyboard
event visual test only, musical-output objective shifted/reported.

**Family:** We tested a dry musical interface. Ask, "What connected an input
to a note?" Describe paper rhythm model if hardware was unavailable.

## Teacher artifact pack (lesson-specific release checklist)

- **Student material (print/no-print):** Print a two-sided **No-Body-Contact Makey Makey Music Interface** card. Side A fields are `Board/model ID ____`, `Matching manufacturer guide/date checked by teacher ____`, `Approved EARTH-closure method ____`, `Pad A label SPACE / Scratch note 60`, `Pad B label LEFT ARROW / Scratch note 64`, `Trace A: dry foil contact → insulated lead → board input → key event → note ____`, `Trace B ____`, and a table for each pupil's `A test 1`, `A test 2`, `B test 1`, `B test 2` with `correct note / not yet`. Side B has four beat boxes `1 __ 2 __ 3 __ 4 __`, `Peer heard/identified ____`, `Pad label/layout revision ____`, `Equal retest result ____`, and `Why the musical choice is intentional ____`. No-print pupils copy the test table and beat grid; the teacher supplies the verified connection diagram rather than asking pupils to invent wiring.
- **Evidence and answer guidance:** Real-operation evidence requires two distinct dry closures for each mapped pad, the correct input-key-note trace, four separate beats in an intentional A/B order, peer interpretation, one label/layout change, and repeat tests. Accept any four-beat sequence (for example `A A B A`) when it is performed as four distinct closures and the pupil explains repetition/contrast. `Foil completes an approved input path; the Makey Makey sends the mapped key; Scratch produces the note` is acceptable. Do not accept required skin-to-EARTH holding, person-to-person circuits, wet/food conductors, simultaneous-pad ambiguity, `foil makes sound by itself`, or a watched demonstration as individual operation.
- **Worked example and finished example:** Using the actual approved board/guide, diagram the insulated EARTH lead ending in a dry foil contact/probe and separate foil pads connected to SPACE and LEFT ARROW; include the teacher-approved closure action exactly as documented. Record A twice as note 60 and B twice as note 64. Compose `A-B-A-A`; peer initially reports `last two pads hard to locate`. Revision: move pads farther apart and add raised cardstock `A/SPACE` and `B/LEFT` labels, without changing wiring or Scratch mapping. Equal retest records both inputs correct twice and the four beats identified. Finish `alternating pitch creates contrast, then repeated A closes the pattern`. If the issued model does not approve this closure method, mark the example **N/A--paper system trace only; conductivity/device operation not observed** rather than improvising.
- **Visual example and board setup:** Draw the complete approved chain `DRY CONTACT CLOSURE → EARTH + ONE INPUT → MAKEY MAKEY → SPACE/LEFT KEY EVENT → SCRATCH MUSIC EXTENSION → NOTE 60/64`; do not draw a child holding EARTH. Add two large labeled pad shapes and a numbered four-beat grid, plus `one closure at a time`, `default tempo stays constant`, and the Scratch blocks exactly as shown in the lesson. Each station shows board/model ID, approved connection diagram, low-volume/silent visual alternative, and status card `PREFLIGHT PASSED` before release.
- **Discussion with acceptable response, and misconception:** Ask `What physically closes the approved path?` (the documented dry foil contact/probe method, not compulsory body contact); `Does foil create the note?` (no--it enables input; board/software map the event to sound); `Why might an approved dry material still fail?` (loose clip, incomplete contact, mapping/USB/software issue, or material/contact geometry); `Why test A and B separately?` (to isolate mappings and avoid simultaneous inputs); `What is a fair interface retest?` (same mapping/pattern after one label/layout change); `How is rhythm different from random touching?` (four distinct, intentional beats); and `Does the device understand the song?` (no--it responds to input events). Correct the misconception that any object or any touch conducts sufficiently.
- **Kit contents, kit label, cleanup and reset:** Kit label: **S16 MAKEY MAKEY--TEAM __--MODEL/ASSET __**, applied to each team station. It contains exactly 1 approved board, 1 compatible school computer, 1 manufacturer USB cable, 1 cardstock base, 3 insulated clip leads, and three 10 cm foil squares (Pad A, Pad B, dry contact/probe); issue two plain sheets and one pencil per pupil. The verified local Scratch 3 project with Music extension is stored on the computer, not a physical `sound page`. Before pupil use, the adult checks the model guide, board/USB, approved EARTH closure, saved/reopened project, low volume, and both mappings twice. Reset is adult-led: stop project, disconnect USB before changing clips, remove/recycle dry foil, count three leads, inspect cable/board, save the local project/evidence, close software, and return assets by ID.
- **Unfinished work:** Stamp one or more exact statuses: `SYSTEM TRACE ONLY`, `A OPERATED`, `B OPERATED`, `FOUR-BEAT PATTERN ON PAPER`, `REVISION NOT RETESTED`, or `DEVICE OPERATION COMPLETE`. Preserve the labeled wiring diagram and rhythm grid. Missing individual turns are rescheduled; watching is not converted to operation. Without matching manufacturer approval, a compatible computer, Music extension, or a safely preflighted closure, use pad/event/note cards; mark conductivity/device or musical-output objective **not observed** as applicable.
- **Annotated exemplar, common error and reteach:** Callouts identify `approved no-body closure`, `EARTH/input path`, `two mappings`, `four separate operation results`, `rhythm`, `interface revision`, and `retest`. No response on both pads suggests adult checks USB/project/approved EARTH path first; one failed pad suggests isolating that input lead/contact; wrong note with correct key event suggests Scratch mapping; held/repeating sound means closure was not distinct. Pupils never add power or rewire live. For rhythm errors, disconnect/stop and clap or point through four boxes before rerunning; for systems-language errors, sequence physical cards from contact to note.
- **Safety classification:** **Severity: moderate; likelihood: unlikely** after preflight, covering damaged USB hardware, a sharp clip/foil edge, heat, or inappropriate electrical experimentation. Adult ratio: **1 adult to no more than 6 pupils at active stations**. Adult alone plugs/unplugs USB, changes wiring, and handles a warm, frayed, cracked, failed, or liquid-exposed unit; pupils use dry foil on a cardstock base, one input at a time, with no external battery/mains, wet/food materials, board modification, required body contact, or person-to-person circuit. Stop, disconnect, label **OUT OF SERVICE**, and report faults. SDS is not applicable to intact USB electronics, insulated leads, aluminum foil, cardstock, paper, or pencils; any cleaning agent or substituted conductive compound requires school SDS/product approval outside this lesson.
- **Print/accessibility check:** Use 18-point labels, thick-line connection diagrams, letter/word labels in addition to lead color, high-contrast/tactile cardstock pad borders, and four spacious beat boxes. Provide low volume, headphones only if school policy permits and never as a requirement, or the Scratch visual event as a silent alternative. Offer mounted pads, switch-like contact assistance, pointing/composer roles, partner or adult physical operation, oral responses/scribing, and repeated turns so motor or hearing access does not erase systems reasoning.
- **Device compliance:** Required technology is limited to school-owned Makey Makey assets and compatible computers, the matching manufacturer instructions already obtained by the teacher, and a verified private/offline Scratch 3 project with Music extension. No student account, cloud save, online piano, personal device, web browsing, microphone, camera, recorded audio, upload, analytics, or personal data is authorized. Record asset IDs and preflight locally; if offline/privacy/installation approval is absent, use the paper fallback and report operation not observed. Paper/unplugged work is not executed-device evidence; until the approved device or hardware turn is witnessed, operation remains deferred/not observed.
