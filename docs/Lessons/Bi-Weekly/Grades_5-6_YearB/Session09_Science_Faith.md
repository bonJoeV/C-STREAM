## VOCABULARY / TEACHER BACKGROUND

**Observation:** inspected information. **Inference:** interpretation.
**Provenance:** origin. **Faith teaching:** belief communicated by Church.
**Common misconception:** science only asks HOW, faith only WHY.
Questions overlap; methods/claims differ. **If asked, "Was there never conflict?"**
This packet cannot establish universal history; study episodes with sources.

**A:** "This line is 10 cm" -> measure/inspect; actual value may differ.
**B:** Adapted from the original
[Mendel heritage card](../../../Resources/Catholic_Scientists_Heritage.md#gregor-johann-mendel-observation-and-inquiry).
[Masaryk University's Mendel Museum](https://mendelmuseum.muni.cz/en/about-the-museum/mendel-museum)
identifies Mendel's Augustinian membership/abbacy, pea experiments and preserved
work/objects. Paraphrase supports role/work, not private motives, every
inheritance pattern or a universal claim about Church/science history.
The child's own line measurement in A remains separate inquiry evidence;
the biography does not replace it.
**C:** [Fides et Ratio, opening](https://www.vatican.va/content/john-paul-ii/en/encyclicals/documents/hf_jp-ii_enc_14091998_fides-et-ratio.html)
affirms faith/reason toward truth; Church teaching, not measured pea result.
**D:** "Every Catholic institution always accepted every scientific theory"
-> unsupported absolute, omit. No quotation required.

## EXACT LESSON SEQUENCE

1. **0-4 (4 min):** Ask "Would the same evidence support all four claims?"
2. **4-11 (7 min):** Read packet; model source type/provenance/date/limit.
3. **11-25 (14 min):** Each measures A, classifies A-D with reasons and makes three-panel explanation observation/history/faith.
4. **25-35 (10 min):** Peer challenges one claim; revise caption/source specificity. Keep unresolved question rather than invent an answer.
5. **35-41 (6 min):** Individual supported claim/source/date/limit, rejected absolute and original/revised explanation.
6. **41-45 (4 min):** Save records/posters, cap/count tools, reuse paper and tidy.

## QUESTIONS TO ASK STUDENTS / WHAT SUCCESS LOOKS LIKE

"What does C establish? What would check B? Why not repeat D?"
Each supplies correct claim/source match, limit, provenance and meaningful
revision. 1 unsupported; 2 prompted; 3 independent; 4 distinguishes inference/
source dependence; NE for missing, no required predetermined historical verdict.

## IF THINGS GO WRONG / SAFETY

Line differs -> record actual, correct card. Source offline -> supplied packet;
no unsupervised browsing. Missing ruler -> teacher-verified mark, measurement
practice deferred. No personal belief survey, private records, public media
or copied quotes/images. Stop/report unsafe data use.

## SUPPORT / CHALLENGE / INDOOR FALLBACK

Grade 5/support: read aloud, claim-type icons and scribing.
Grade 6/challenge: explain why one scientist's example cannot establish all
history, suggest needed source. Indoor packet plan.

## CLEANUP / FAMILY NEWSLETTER

Keep individual source/limit and revision, count tools, log open questions.
**Explored:** faith/reason and claims. **Did:** inspected/cited/revised.
**Learned:** appropriate evidence. **Catholic connection:** truth with humility.
**Ask:** "Which source fits your claim?" No routine homework.
