# Session 10: Environmental Science

## LESSON AT A GLANCE

| Field | Reference |
|---|---|
| Grade / schedule / rotation / unit | 5-6 / Bi-Weekly / A / Environment |
| Time | 1 meeting of 45 minutes |
| Objective / why / big idea | I can graph fictional counts, define a resource criterion and defend a limited reuse proposal. A comparison doesn't prove an environmental intervention caused change. |
| Domains / Catholic connection | C, E, M; stewardship considers waste and users needing clean paper. |

## BEFORE CLASS / MATERIALS

Review contact/accommodations; tool teams 4/5/7/9. Copy invented classroom
paper-scrap counts: before days 1/2/3 = 12/14/10 sheets; after = 9/11/10.
No real school waste measurement. Draw bars 0-14 and reusable/clean-paper
choice sign. Brief: "Users need to locate usable blank-back paper without
private writing exposed." Test peer finds REUSE and CLEAN choices at 50 cm.
Only clean school paper scraps, not actual trash or documents with names.

Paper consumable/reused; tools reusable.

## VOCABULARY / TEACHER BACKGROUND

**Stewardship:** responsible resources. **Count:** defined quantity.
**Criterion:** success check. **Confound:** another possible influence.
**Common misconception:** fewer scraps proves campaign success.
**If asked, "Can we sort bins?"** No; supplied clean paper/pictures only.
Key totals 36/30 sheets; difference 6; means 12/10 if taught.
Counts could change with attendance/workload; no causal savings claim.

## EXACT LESSON SEQUENCE

1. **0-4 (4 min):** Ask "What evidence would responsible reuse need?"
2. **4-11 (7 min):** Model fictional source, grouped bars and 36/30 sums.
3. **11-25 (14 min):** Each plots six bars/total; teams define sign criterion and create two-choice layout.
4. **25-35 (10 min):** Peer finds both choices; record confusion and revise. Discuss privacy versus reusing every sheet.
5. **35-41 (6 min):** Individual graph/6-sheet comparison, criterion and resource/privacy/causal-limit explanation.
6. **41-45 (4 min):** Store clean scraps, return tools, save graphs/signs and tidy.

## QUESTIONS TO ASK STUDENTS / WHAT SUCCESS LOOKS LIKE

"Were counts measured? What else changed? Which scraps shouldn't be reused?"
Each has six correct bars/total, numerical comparison, sign criterion and
stewardship limit. 1 unsupported; 2 prompted; 3 independent; 4 further-data
plan; NE if missing.

## IF THINGS GO WRONG / SAFETY

No graph paper -> ruler axes. No scraps -> draw choices, no claim of real reuse.
Misleading sign -> add words/contrast, keep clean option. No trash, unknown
water/soil, meter access, private papers, installed equipment or compulsory
home audit. Stop/report contamination/privacy issue.

## SUPPORT / CHALLENGE / INDOOR FALLBACK

Grade 5/support: prelabelled axes, total scaffold, oral/scribed response.
Grade 6/challenge: compare means and matched-day protocol limitations.
Indoor table path unchanged in Minnesota winter.
