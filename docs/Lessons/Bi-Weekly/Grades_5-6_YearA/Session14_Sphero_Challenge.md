# Session 14: Sphero Challenge

## BEFORE CLASS / MATERIALS

Review contact/accommodations. Seat 4/5/7/9 teams; rotate operator/tracer/checker.
Draw 5x5 paper grid: start (0,0), goal (2,2), right/up positive. Commands
RIGHT 2 / UP 2; intentional bug RIGHT 2 / DOWN 2 reaches (2,-2), outside
grid, so mark invalid instead of moving off table. Paper token remains seated.
Optional actual setup/team: adult-approved Sphero Edu, charged BOLT/tablet,
clear 1 m lane, 50 cm observer boundary; mark 30 cm straight target. Pretest
low-speed roll at aimed heading 0, speed <=20, duration <=1 second, Stop.
Adjust duration using actual endpoint; heading zero is aimed frame, not north.
No directional light-seeking or collision mission. Adult checks the actual
removable floor-marking tape's adhesion/removal compatibility on the school's
surface; generic masking/painter adhesive is not an automatic substitute.

Paper/tape consumable; tools/devices reusable. Choose simultaneous or shared
hardware/tape rows, never add them. No device/lane holding is assumed.

### Optional shared-kit turn plan

With three approved BOLT/tablet setups and three safe marked lanes, preload
the exact bounded roll/Stop program above. Keep 4/5/7/9 balanced teams <=3:
two trios/two pairs, five trios, six trios/one pair, seven trios/two pairs.
Teams 1-3 use **11-19**, 4-6 **19-27**, 7-9 **27-35**; 10/15 then retest.
Each pupil has up to two minutes to personally run the original duration,
measure its stopped endpoint, edit duration within the <=1 second/speed<=20
caps, rerun and record the second endpoint. Three operators produce three
baseline/retest pairs/team; a two-pupil team uses the spare third turn to
repeat one pair, preserving three trials/condition. Two minutes/team cover
stopped reset/checking.
Waiting pupils complete their independent grid trace and debug reason.
Adult pretests access, lane coverage, safe retrieval and turn timing; the
demo uses an issued station. Never count watching as operation. If only
one/two safe staffed setups exist, that many teams use each window and others
book later hardware checks, recording paper-only/NE without enlarging groups
or compressing safety/accommodations. No paper endpoint is called measured
robot motion.

## VOCABULARY / TEACHER BACKGROUND

**Algorithm:** instructions. **Heading:** aimed direction reference.
**Debug:** locate/fix error. **Retest:** repeat criterion.
**Common misconception:** same roll duration always travels identical distance.
**If asked, "Can we go faster?"** No; change within safe duration/precision limits.
Paper Manhattan steps total 4; wrong/down has invalid endpoint. Real endpoint
error = measured distance from target, e.g. 28 versus 30 cm -> 2 cm; do not
call this theoretical speed calibration or paper distance a robot measurement.

## EXACT LESSON SEQUENCE

1. **0-4 (4 min):** Ask "What evidence finds a wrong route?" Introduce cooperative roles.
2. **4-11 (7 min):** Model paper endpoint and optional real Stop/boundary setup.
3. **11-25 (14 min):** Each traces buggy/correct route; optional teams assemble finite roll/Stop, each edits/runs a supervised short trial. Shared hardware teams begin their stated waves.
4. **25-35 (10 min):** Paper pupils fix DOWN and repeat from start; optional pupils record three endpoints, revise one duration within cap and retest. Finish shared waves; keep each pupil's measured pair distinct from paper traces.
5. **35-41 (6 min):** Individual trace, revision/result/limit and safe equitable-role reason; log device turn only if observed.
6. **41-45 (4 min):** Stop before adult retrieval, save records, return devices/tokens and tidy.

## QUESTIONS TO ASK STUDENTS / WHAT SUCCESS LOOKS LIKE

"Did you reset start? What changed? Was endpoint measured or modeled?"
Each has valid trace/debug/retest and access/safety decision.
1 unsupported; 2 prompted; 3 independent; 4 explains repeat variability;
NE for unobserved actual robot operation.

## IF THINGS GO WRONG / SAFETY

No device/approval/lane -> paper core, record real programming deferred.
Robot drifts -> Stop, re-aim/check surface with adult, no speed increase.
No races, collisions, shaking, moving retrieval, battery handling, bright
lights in eyes or public accounts. Adult isolates/reports damaged/hot equipment.

## SUPPORT / CHALLENGE / INDOOR FALLBACK

Grade 5/support: arrow cards, large grid, oral/scribed trace.
Grade 6/challenge: compare real endpoint variation or paper alternate route
with same goal; no speed prize. Indoor seated/lane plan only.

## CLEANUP / FAMILY NEWSLETTER

Keep original/retest data and route labels; count tools, report gaps.
**Explored:** precise instructions. **Did:** fixed/retested one mission.
**Learned:** reset and evidence. **Catholic connection:** cooperation.
**Ask:** "How did you find the error?" No routine homework.
