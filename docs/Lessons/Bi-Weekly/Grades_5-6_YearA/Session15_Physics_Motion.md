## BEFORE CLASS / MATERIALS

Review contact/accommodations. Seat 4/5/7/9 teams; pilot ramp at 3/6 cm
book heights into 60 cm tray, same soft ball release point. Ball must stop
before tray end; reduce both heights if necessary and record.
Copy force cards: gravity Earth on ball / ball on Earth; foot pushes ground
back / ground pushes foot forward. No live rocket/balloon or tablecloth stunt.

## VOCABULARY / TEACHER BACKGROUND

**Force:** push/pull interaction. **Inertia:** resistance to changing motion.
**Acceleration:** change in velocity. **Force pair:** forces on different objects.
Balanced forces on one object differ from third-law pair.
**Common misconception:** gravity gets stronger on a steeper ramp.
Same ball's weight essentially same; downhill component changes.
**If asked, "Did distance measure acceleration?"** No; stopping distance is
an outcome influenced by release, friction and surface. We haven't measured
time/velocity to calculate acceleration. F=ma is conceptual context only.
Worked fictional distances 12/14/13 and 19/21/20 cm; compare 13/20 cm means
if taught, not expected results.

## EXACT LESSON SEQUENCE

1. **0-4 (4 min):** Ask "What changes a resting ball's motion?" Introduce honest physics/faith distinction.
2. **4-11 (7 min):** Model release/ruler, gravity pair and why two forces act on different objects.
3. **11-25 (14 min):** Rotate releaser/measurer/recorder, run three rolls at each height; each records six values with cm and controls.
4. **25-35 (10 min):** Compare outcomes, draw Earth/ball and foot/ground arrows; peer checks objects, correct same-object mistaken pair.
5. **35-41 (6 min):** Each student independently explains one accurate force pair, cites a measured outcome/limit and distinguishes physical law from moral/theological reflection.
6. **41-45 (4 min):** Retrieve balls, stack supports, remove tape, save records and tidy.

## QUESTIONS TO ASK STUDENTS / WHAT SUCCESS LOOKS LIKE

"Which object receives each force? Did we measure acceleration?"
Each has six values/units, correct two-object pair, limit and faith distinction.
1 unsupported; 2 prompted; 3 independent; 4 explains a confound;
NE for unmeasured operation.

## IF THINGS GO WRONG / SAFETY

Wall hit -> invalid trial, adult reduces both heights. Missing kit -> fictional
data analysis/diagrams, measurement deferred. No launches, balloons, glass,
coins, crashes, pushing balls, students in paths or high ramps (>15 cm).
Stop/report unstable supports or injury.

## SUPPORT / CHALLENGE / INDOOR FALLBACK

Grade 5/support: ruler guide, two-object arrow template, oral/scribed answer.
Grade 6/challenge: explain why a stopping-distance trend doesn't isolate force/
acceleration. All tests indoors with catching trays.
