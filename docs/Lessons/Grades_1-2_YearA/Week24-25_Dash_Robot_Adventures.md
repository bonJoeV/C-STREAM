## Before class

1. Assign teams of at most three: **4 / 5 / 7 / 9** kits for **10 / 15 / 20 / 25** pupils. Keep work at tables; distribute materials, not roaming station rotations.
2. Charge/check three Dash kits; connect each tablet, open a new Blockly project and pretest Start -> Drive Forward at low speed for a short distance -> Stop. Mark three 1 m clear floor lanes with start/end zones. Match installed controls to picture cards; test finite Repeat 2 with the drive block before class.
3. Put two plain-paper sheets per child per meeting and crayons at tables. Draw this record on the board: **predicted endpoint / actual travel / changed instruction**. Children copy boxes/icons, not paragraphs. Teacher dates and saves each child's record between meetings.
4. Read the SAFETY section, pretest the actual task with one issued kit and put a roster beside the timer. Demonstrate orally with objects; read every direction aloud. No independent reading, Year A completion or family donation is a prerequisite.

## Vocabulary and teacher background

Program = stored instructions; input = selected instruction; output = movement; finite repeat = a fixed number of repetitions.

Wheel travel varies by floor and settings. Prediction and comparison require the same start, heading, floor and measured unit.

**Common misconception:** Manual steering or successful group travel proves every child programmed.

**If asked:** "Does a robot follow God's plan?" A robot executes human instructions; our moral choices are not robot commands.

## SAFETY

Three dry low-speed lanes away from exits; no riders, added markers, collisions or moving across walking routes. Adult handles charging and damaged devices. Keep aisles/exits clear. Stop for damaged materials; do not improvise a hazardous replacement. No student handles loose batteries or teacher cutting tools.

## Meeting 1: Transfer a stored sequence - 30 minutes

1. **0-3:** Reintroduce Run/Stop and safe lane use; no prior hardware experience assumed.
2. **3-7:** Teacher connects two drive blocks after Start, predicts endpoint, runs, stops and resets to the same start.
3. **7-20:** Use two waves for 10/15 pupils or three for 20/25, four minutes each, three teams per wave. Each member has about 40 seconds to select/change a block, predict, Run/Stop and identify output; other teams plan on cards.
4. **20-26:** Each child records travel in equal ruler lengths/cm and explains the changed instruction. Teacher notes actual device actions during waves; pending turns are not scored independent.
5. **26-30:** Stop robots, return to local project home, park in numbered dry charging storage and remove lane tape. Collect each child's dated evidence, count kit items, return tools and clear tables. Cleanup is part of the period, not time added afterward.

## Meeting 2: Finite repeat and comparison - 30 minutes

1. **0-3:** Recall one measured run and recheck the saved sequence.
2. **3-7:** Compare two explicit short forward blocks with Repeat 2 containing one identical forward block; Run both from same start.
3. **7-20:** Use the same four-minute waves. Each child predicts a finite repeat, runs or changes repeat count with supervision, resets and compares the endpoint. Cards keep waiting teams tracing the same program.
4. **20-26:** Each child shows the repeated action and number of repeats, compares measured output and explains a resource-care action: careful return/sharing, not fastest-run bragging.
5. **26-30:** Stop robots, return to local project home, park in numbered dry charging storage and remove lane tape. Collect each child's dated evidence, count kit items, return tools and clear tables. Cleanup is part of the period, not time added afterward.

## Questions to ask

- Which instruction changed the robot's output?
- What action repeated and how many times?

## Individual evidence and success

**Grade 1:** Individually Run/Stop a stored sequence and identify a changed action; trace Repeat 2 with two cards.

**Grade 2:** Predict and execute/modify a finite repeat, compare two measured outputs and explain why start/heading must be reset.

Teacher visits three table teams during each of the first three four-minute blocks of practice (7-19), listening to or observing each member briefly; use the remaining practice minute and 20-26 for unfinished checks and comparison. At 25, this is nine table visits, **not 25 presentations**. Where a meeting specifies waves, use its supervised wave/check schedule instead of simultaneous table visits. Children keep separate records and partners may not answer for each other. Score each stated criterion **not yet / prompted / independent**; record absent/unobserved evidence as such. A group product, attendance, attractive art or a certificate is not individual mastery. No hardware/loop mastery is claimed on a card-only route.

## Support and challenge

**Support / nonreader access:** Provide a connected starter script and large block pictures; permit partner positioning under child direction. Adult scribing, pointing, tactile/large pieces and a seated partner-directed action can show understanding; do not score motor speed. Record who actually operated hardware/software: a partner's operation does not establish the child's independent operation.

**Challenge:** Explain why an identical repeated code may produce slightly different measured endpoints. Do not add an unprepared activity or extend the native period.

## If things go wrong / indoor alternative

Only one/two kits: fewer individual device turns fit; teach token sequencing now and record remaining device checks unassessed. No Repeat control: use two explicit identical blocks; finite-loop execution is unassessed. Failure to connect: adult restarts the app/pairing; never count manual Go driving as code.

**Indoor:** The marked indoor floor lanes are the primary route; use desktop cards if safe clear floor space is unavailable.

## Family copy - optional, no routine homework

We tested stored robot instructions and finite repeats, comparing measured travel and sharing tools responsibly. Ask: "Which instruction changed the robot's output?" Optional: trace two repeated spoken actions with a paper token. No purchase, donation, device, home teaching or required take-home project.
