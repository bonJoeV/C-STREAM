# Weeks 2-3: Sphero Coding Adventures

## Lesson at a glance
| Field | Teacher information |
|---|---|
| Grade / unit / title | Grades 1-2 / Coding / Sphero Coding Adventures |
| Time | Two meetings of 30 minutes; 60 minutes total |
| Domains | C: responsible sharing; T: input/output and algorithms; M: comparing travel |
| Big idea | A stored sequence runs without continuous steering; observations help us debug. |
| Student objective | "I can predict a short program, run it, and change one instruction." |

| Official standards | VERIFICATION REQUIRED; no Minnesota/Archdiocesan/CSTA benchmark claimed. |

## Before class
1. Confirm loan/inventory, exact robot model, current app compatibility, school-approved permissions and charging instructions; do not assume a class set exists.
2. On each device create a tested Blocks starter: roll at heading 0, low speed for 1 second; stop; delay 1 second; roll at heading 180 for 1 second; stop. Labels vary by app version: use its installed help. Do not invent a "turn right" block.
3. Aim/calibrate heading 0 away from students. Test on the actual surface; shorten duration/speed until travel stays inside a 1 m square. Teacher records working settings on the board.
4. Mark dry floor bays with clear walking aisles, never across an exit. Make arrow cards for forward, wait, return, stop; no printing needed.
5. Assign teams of 2-3: programmer, observer, safety checker. Swap after each run; teams of two combine observer/checker.

## Supplies and class sizes
- **Per student:** one half-sheet and crayon; an individual evidence box on teacher roster.
- **Per team:** one robot/tablet pair, four arrow cards, one 1 m paper measuring strip with equal hand-width marks.
- **Class reusable/consumable:** floor tape, timer, whiteboard; one dry bay per active robot.
- **Teacher-only:** charger, model-specific help, roster. No water, paint, attached markers, or robot disassembly.

| Students | Teams of at most 3 / kits for simultaneous work | Paper sheets |
|---|---:|---:|
| 10 | 4 | 10 |
| 15 | 5 | 15 |
| 20 | 7 | 20 |
| 25 | 9 | 25 |

With fewer kits use **one supervised robot station**, not nine unsupervised moving robots. In the 12-minute practice block use three 4-minute waves (three teams per wave for 25 students); other teams predict on paper. With only one kit, this is a demonstration/partial practice lesson: record children not yet assessed and schedule another opportunity. Do not certify everyone from a group run.

## Vocabulary
Sequence = instructions in order; program = stored instructions; input = our code; output = observed movement; debug = change an instruction after comparing prediction and result; loop = repeat instructions.

## Teacher background
Heading is a direction measured from the robot's calibrated aim; rolling at 180 reverses travel relative to 0. Actual distance depends on speed, time, surface and calibration. A joystick is remote control, not evidence of a stored program.
**Misconception:** a failed path means the child failed. Treat it as information.
**If asked "Does it think like me?"** This classroom robot runs human-written instructions and sensors; people remain responsible. Avoid claims about every kind of robot.

## Exact sequence: meeting 1 (30 minutes)
1. **0-3:** State objective, stop signal and sharing rule. Optional original prayer: "God, help us use tools carefully and tell the truth about our tests."
2. **3-7:** At tables move a paper token for forward-wait-return cards. Each child predicts the ending by pointing.
3. **7-11:** Teacher shows aim, stored blocks, Run and Stop. Contrast one joystick movement with a hands-off stored run.
4. **11-23:** Teams run the tested starter. Each child points to the next block before their own run; observer compares start/end. Shorten one roll duration and rerun. Teacher records each child's run/stop or "not yet observed."
5. **23-26:** Individual oral/drawn exit: show the three actions in order; identify one observed difference between two runs.
6. **26-30:** Cleanup below; partners check care and equitable turns.

## Exact sequence: meeting 2 (30 minutes)
1. **0-4:** Re-aim robots and retell one sequence; newcomers receive a two-card demo rather than assumed prior mastery.
2. **4-8:** Model a deliberate too-long roll. Ask which instruction should change; show one shorter duration.
3. **8-20:** Each child predicts, runs and changes one parameter. Compare travel on the same surface using the marked strip. Grade 2 may repeat a short out-and-back sequence twice in a finite repeat block; this is not a guaranteed square.
4. **20-24:** Partner demonstration: original run, change, rerun. Teacher asks each child what changed and why.
5. **24-26:** Individual exit and roster check; identify anyone still needing a device opportunity.
6. **26-30:** Cleanup.

## Questions and measurable evidence
- What happens without touching the joystick? Which block changes the result? What stayed the same? Did every partner get a turn?
- **Grade 1:** point to/orally order three action cards; personally Run and Stop under supervision; name/draw one change. Compare longer/shorter travel with a marked strip.
- **Grade 2:** create a three-action stored sequence, predict ending, change one parameter and explain both observed results; count equal travel units. Finite loop is challenge, not universal mastery.
- Use **0 not observed / 1 with prompt / 2 independently** for each criterion. A successful team path or enthusiasm alone earns no individual code credit.

## If things go wrong / indoor and no-device fallback
Connection failure: check charge and selected robot once; after 2 minutes use arrow cards and a tabletop token with the same timed blocks. Mis-aim: stop, re-aim, lower speed; change only one parameter. Finish early: make a second prediction, not a speed race.
**No devices:** each child orders three cards, another follows literally, then the child repairs one deliberately wrong card. Mark CST-T2 algorithm evidence only; CST-T1 physical robot operation is **not assessed**. All work is indoors; no weather requirement.

## SAFETY
Only low-speed floor runs inside marked bays; seated/kneeling observers outside the bay; never chase or stand in a moving path. Teacher stops any robot leaving its area. Cords remain teacher-only and off walking routes. Follow model age/use guidance, especially small Mini components. No direct-contact assistance without consent.

## Support / challenge
Support: two actions first, picture cards, adult scribing, accessible table token, peer explains buttons but does not take the child's turn. Grade 1 needs no reading or writing.
Challenge: Grade 2 compares two trials at one changed duration or explains a finite repeat; no variables or autonomous navigation claim.

## Cleanup
Stop all programs, power down per model instructions, count kits/cards, peel only lesson tape, return devices to labeled trays; teacher handles charging. Retain each child's prediction/change sketch.

## Family snippet
**What we explored:** instructions that control a robot. **What we did/learned:** predicted a stored sequence and used observations to fix it. **Catholic connection:** fair turns and careful use of shared tools. **Ask:** "What did you change after your first test?" **Optional at home:** give three spoken directions to move a paper token; no purchase or device needed. No routine homework.
