# C-STREAM templates

October 2026 formats for K-6; complete bracketed fields before teaching.
Native periods: K 25, grades 1-2 30, grades 3-4 40, grades 5-6 45 minutes.

C is Catholic identity; R is religion/faith integration; A is arts **including
music**; M is mathematics. Art includes observation, composition, design,
performance and communication without a screen; it is not merely decoration.
Only claim domains genuinely practiced. All required work and supplies are
provided at school; no routine homework or donation prerequisites.

| Creating... | Use | What it protects |
|---|---|---|
| One meeting | [Lesson plan](./Lesson_Plan_Template.md) | At a glance, background/vocabulary, native timings, safety, scaling and individual evidence |
| A unit | [Cross-curricular unit](./Cross_Curricular_Unit_Template.md) | Prerequisites, meeting sequence, balance, logistics, family copy |
| Multi-meeting project | [PBL overlay](./Project_Based_Learning_Template.md) | Launch/research/create/present using the same unit and lesson formats |
| Student response | [Student sheet](./Student_Sheet_Template.md) | Show/tell/draw or record; nonreader route |
| Substitute handoff | [Substitute lesson](./Substitute_Lesson_Template.md) | 20-minute preparation gate and named fallbacks |
| Individual evidence | [Assessment](./Assessment_Template.md) | Objective -> prompt -> success condition -> student evidence |
| 3/4-level criteria | [Rubric](./Rubric_Template.md) | Observable objective-linked levels, not participation or polish |
| Family copy | [Newsletter](./Family_Newsletter_Template.md) | Actual learning and optional no-purchase conversation/activity |
| Materials/kit | [Materials list](./Materials_List_Template.md) | Normalized items, 10/15/20/25 quantities and replenishment |
| Standards evidence | [Standards mapping](./Standards_Mapping_Template.md) | Local catalog and separately verified official alignment |

The [local 18-code catalog](../Review/Local_Standards.md) defines CST-C1..C3,
CST-S1..S3, CST-T1..T3, CST-E1..E3, CST-A1..A3 and CST-M1..M3.
Do not generate new local codes or label these official Archdiocesan/Minnesota
standards. Official source questions remain **VERIFICATION REQUIRED**.
