## 📋 Teacher Notes

**When to Use:** Any engineering/building project  
**Time Needed:** Use selected sections within the lesson's native period; do not add 5-10 minutes for every section.
**Grades:** Best for 1-6 (simplify for K-1 by using just draw/build/test)

### Tips for Use

- **Grades K-1/nonreaders:** Adult shows a real object, says one step and models it. Use [Show, Try, Tell](./Show_Try_Tell_Card.md); accept pointing, building, oral response or scribing rather than independent reading.

- **Grades 2-3:** Complete all sections with sentence starters.

- **Grades 4-6:** Add detailed explanations and data collection.

Teacher completes the objective, individual prompt and success condition using
[Assessment Template](../Templates/Assessment_Template.md). A completed team
sheet or neat drawing is not proof of each child's learning. Do not grade
handwriting/artistic talent unless it is the explicit objective. Link only
practiced codes from [Local Standards](../Review/Local_Standards.md).
