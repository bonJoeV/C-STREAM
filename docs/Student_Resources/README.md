# Student resources

Print only what the objective needs; a board-drawn prompt or oral response is
equally valid. No reading/writing prerequisite for K-1. Adult models one step
and accepts point/show/build/sort/tell/dictate; each child gets their own turn.

| Resource | Purpose and use |
|---|---|
| [Show, Try, Tell](./Show_Try_Tell_Card.md) | Actual nonreader/adult-led comparison example and reusable response route |
| [Journal cover](./STREAM_Journal_Cover.md) | Optional personalized cover; black-and-white/hand-drawn works |
| [Goals](./My_STREAM_Goals.md) | Interest/next-learning conversation; not an achievement grade |
| [Engineering process](./Engineering_Design_Process.md) | Plan/test/improve evidence; select fields, not a mandatory long worksheet |
| [Wonder journal](./Wonder_Journal_Page.md) | Questions/observations; enjoyment stars are not mastery |
| [Project reflection](./Project_Reflection.md) | One objective/evidence prompt at a time; full reflection optional |
| [Student sheet template](../Templates/Student_Sheet_Template.md) | Teacher adapts objective, prompt, criterion and evidence mode |

Use [assessment](../Templates/Assessment_Template.md) and
[rubrics](../Rubrics/README.md) for individual learning. Do not grade
participation, handwriting, neatness or apparent faith as subject mastery.
Arts skills are assessed only if explicit objectives; A includes music and M
means mathematics. Named records follow the school's actual privacy practice.
Local standard definitions: [Local Standards](../Review/Local_Standards.md);
official alignment/source questions require verification.
