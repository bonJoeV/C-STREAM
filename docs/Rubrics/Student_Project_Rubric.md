# Student project rubric

**October 2026 revision.** Replaces the universal 100-point weighting with a
small selection of criteria matched to the taught objectives. Preserve science/
engineering, faith reasoning, service, communication and reflection as possible
learning purposes, not compulsory scoring categories for every project.

## Before use

1. Write grade/unit/lesson, objective O1/O2, individual prompt and success
   condition using [Assessment Template](../Templates/Assessment_Template.md).
2. Select 1-3 relevant criteria below; adjust Meets to the lesson's exact
   measurable threshold and grade prerequisites before teaching.
3. Link the defined [local standard](../Review/Local_Standards.md). Official
   alignment requires verification, not a claim that a score meets all standards.
4. Share expectations by showing/telling students. Offer oral, model, drawing,
   scribed or written evidence. Team products support, but never replace,
   each child's demonstration.

## Four levels

| Objective-linked criterion (use only if taught) | 1 Beginning | 2 Developing | 3 Meets Expectation | 4 Extends Learning |
|---|---|---|---|---|
| O1 scientific observation/comparison | Describes an outcome inconsistent with what was observed | Names a relevant observation but comparison is incomplete | Makes the specified comparison using an observed result | Repeats or transfers the comparison and explains supporting evidence |
| O1 fair test/engineering redesign | Changes conditions without recognizing their effect | Tests and suggests a change but evidence link is incomplete | Uses the stated common conditions, records a result and justifies one redesign | Retests the redesign and compares performance or a tradeoff using evidence |
| O2 measurement/math reasoning | Quantity/unit or comparison is incorrect | Partly correct measure/data with a specific error remaining | Measures/represents/explains using the lesson's specified quantity and unit | Checks the result or uses it to justify a new comparison |
| O2 algorithm/programming | Sequence cannot produce intended result | Sequence partly works; bug or execution evidence remains unresolved | Explains/tests the intended sequence; real execution included if objective requires it | Finds and tests a new correction/condition and explains the effect |
| O2 artistic communication/music | Chosen form/pattern does not yet convey the stated idea | Artistic choice partly conveys the idea/phrase | Uses the stated visual or musical choice to communicate the intended idea/phrase | Revises a composition/phrase after feedback and explains the artistic effect |
| O2 Catholic/ethical/service reasoning | Choice does not yet address the taught dignity/stewardship principle | Names the principle or user but connection to choice is incomplete | Explains a concrete choice and how it respects the taught principle/user need | Compares two choices and explains an evidence-informed tradeoff in light of the principle |

**NE = not yet evidenced**, outside the scale. Missed observation, absence,
device failure or an inaccessible response mode is not Beginning. Access
supports do not cap levels. A conceptual hint is recorded separately.
Artistic skill is scored only for an explicit arts objective; handwriting,
neatness, beautiful displays, expensive boards, confident speech, participation
and family assistance are not mastery criteria. No grades for interior faith,
prayer frequency, family religious practice or apparent enthusiasm.

Do not average unrelated objectives into a pseudo-precise total. Report
"Compared two bridge tests using the same span; next, explain the redesign"
instead of "earned 80%, meets all C-STREAM standards."
Expected-mastery checkpoints follow [Local Standards](../Review/Local_Standards.md):
two dated observations on separate occasions, including an individual
demonstration and changed context/follow-up explanation, both meeting the target.
One project rating does not establish end-of-grade mastery.

## Bridge example and moderation

O1: Compare two paper designs under the same span/load conditions. Meets:
child names the observed result and shows which conditions stayed the same.
A failed prototype can provide successful learning evidence. A team's strong
bridge with no individual explanation is NE for that child's comparison.
Drawings can communicate the comparison without handwriting assessment.

Before a showcase, two teachers score the same anonymized examples using the
selected criteria and resolve discrepancies. Events are optional celebrations
of in-school work; a child's assessment does not depend on home construction,
family attendance or purchased display materials.
