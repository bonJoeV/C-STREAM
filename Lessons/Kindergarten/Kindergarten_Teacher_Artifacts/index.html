    Kindergarten teacher artifact cards¶

    These cards complete the teacher-facing preparation and follow-up artifacts for the linked lesson. Use the lesson's existing quantities and timed sequence; this file does not add time, required purchases, school approvals, or physical stock. “Printable” means a teacher may draw or copy the described large-format item; no student packet is required.

    Week 1 — Welcome to C-STREAM¶

    • Student material: no-print half-sheet divided into “I see” and “I wonder”; provide a large leaf drawing or inspected clean leaf picture.
    • Evidence / answer guidance: each child points to one actual feature and gives one question; accept pointing, dictation, gesture, or drawing. “I see lines” is evidence; “the lines carry water” is a question/idea, not observed evidence.
    • Worked example: board model: leaf with three branches, label “I see a line,” then “I wonder what it does.”
    • Annotated exemplar: point to one drawn branch and circle it as the observed detail; point to the question mark for the unanswered question.
    • Finished example: a dated half-sheet with one circled leaf line and one dictated “I wonder…” question.
    • Adult supervision ratio: one teacher/adult can supervise the seated paper activity; add coverage only if specimens or individual support require it.
    • SDS/product gate: SDS not applicable: no chemical product or purchased product is required; inspect any real leaf before use and use the drawing fallback.
    • Print/accessibility check: no printing required; use high-contrast large drawings, tactile approved models, scribing, or oral/gesture responses.
    • Board setup / discussion: eye icon → leaf detail → question mark. Ask, “What can you point to? What do you still wonder?”
    • Kit and label text: one half-sheet, one crayon, one large leaf card. Label: K W1 — NOTICE / WONDER.
    • Cleanup / reset: collect dated sheets, count crayons and cards, leave one model on the board for the next class.
    • Unfinished work: mark finish next meeting and retain the sheet; do not require a home observation.
    • Misconception / interpretation: a guess is not a detail; ask the child to point to the feature before recording “not yet.”
    • Reteach: use one large leaf with two pictured choices and model “I see…” / “I wonder…” again.
    • Safety classification / supervision: severity: low; likelihood: unlikely. Seated observation only; adult inspects any specimen, with no tasting, smelling, or collecting.
    • Accessibility / print check: large high-contrast drawing; allow tactile approved model, oral response, scribing, and no-print teacher-drawn materials.

    Weeks 2–3 — Exploring Movement with Sphero¶

    • Student material: no-print 3-by-3 grid, paper robot, and large UP/RIGHT/STOP cards; optional device is extension only.
    • Evidence / answer guidance: child predicts two moves, follows the cards, and changes one wrong card. Paper success is algorithm evidence, not robot operation/programming.
    • Worked example: START → UP → UP → STOP → FINISH; show UP, RIGHT missing and replace RIGHT with UP.
    • Annotated exemplar: point to each card in order, then point to the missed FINISH square and the corrected UP card.
    • Finished example: a completed paper grid showing UP, UP, STOP reaching FINISH and one corrected route marked with an arrow.
    • Adult supervision ratio: seated paper work needs ordinary classroom supervision; any Sphero demonstration requires one adult controlling the robot and lane.
    • SDS/product gate: The exact painter's tape brand/product remains HOLD in the SDS register until its current manufacturer SDS and school approval are recorded. Intact Sphero/tablet hardware needs no lesson SDS; remove damaged or leaking batteries from service.
    • Devices/external-service compliance: Optional hardware is one school-approved Sphero, its paired tablet, and the installed Sphero Edu Drive interface. Do not create a student account or upload data. Record hardware evidence only when a child actually drives and stops the robot; otherwise defer H as not assessed and retain the paper algorithm evidence only.
    • Print/accessibility check: no printing required; use large command cards, fixed orientation, adult-directed token movement, and paper-only access.
    • Board setup / discussion: fixed page orientation, START and FINISH, input arrow → output position. Ask, “What did we give it? What did it do?”
    • Kit and label text: grid, paper robot, two UP, one RIGHT, one STOP. Label: K W2-3 — PAPER PATH.
    • Cleanup / reset: return cards to five-card sets, park paper robots at START, stop/store hardware, count kits.
    • Unfinished work: preserve the last route and record paper evidence incomplete; restart at the same START next meeting.
    • Misconception / interpretation: a robot does not know intentions; wrong endpoint means inspect order, orientation, and start condition.
    • Reteach: cover extra squares, offer two pictured arrows, and have the child point while an adult moves the token one card at a time.
    • Safety classification / supervision: severity: moderate; likelihood: unlikely after controls. Optional moving-robot demonstration is low-speed equipment use; an adult handles charging, lane control, stop, and retrieval.
    • Accessibility / print check: seated paper path is the complete alternative; use large cards, consistent orientation, and no tiny tokens or screen requirement.

    Week 4 — Wonder Walk¶

    • Student material: two-box half-sheet, crayon, and clean large leaf/rock pictures or approved specimens; no-print.
    • Evidence / answer guidance: record two specific details and one question, plus one stewardship action. “Bumpy edge” is evidence; “it is alive because it moves” is an error to interpret.
    • Worked example: draw a line in box 1 and a speckle in box 2; say, “I wonder where the line goes.”
    • Annotated exemplar: point to the line in box 1 as evidence and to the question mark beside “where” as a question, not a claim.
    • Finished example: two labeled observation boxes with one specific detail in each and one question dictated beneath them.
    • Adult supervision ratio: one adult may supervise the indoor table pathway; outdoor or specimen work needs the school’s required coverage and headcounts.
    • SDS/product gate: SDS not applicable: no chemical product is used; adult-inspect/clean specimens and replace them with teacher drawings when safety or allergy status is uncertain.
    • Print/accessibility check: no printing required; provide large pictures, tactile approved objects, dictation, and a seated indoor route.
    • Board setup / discussion: eye, two observation boxes, question mark, and open hand. Ask, “What did you actually notice?”
    • Kit and label text: leaf/picture, rock/picture, tray, optional magnifier. Label: K W4 — LOOK / CARE.
    • Cleanup / reset: return specimens to trays, clean approved items, wash hands, retain drawings, and reset the indoor table path.
    • Unfinished work: label the dated sheet and finish the second detail/question at the next seated check.
    • Misconception / interpretation: a guess may sound like an observation; ask “Where can you point?” and record prompted if needed.
    • Reteach: compare one teacher-drawn leaf and rock, offering two detail choices before asking for a question.
    • Safety classification / supervision: severity: low; likelihood: unlikely. Seated handling only; adult inspects specimens, with no unknown plants, tasting, Sun viewing, or outdoor use without coverage.
    • Accessibility / print check: large high-contrast drawings, tactile approved objects, dictation, and indoor no-print fallback; never require sight-only evidence.

    Weeks 5–6 — Building with KEVA Planks¶

    • Student material: two-attempt picture record, six-block build, tray, and crayon; no-print.
    • Evidence / answer guidance: record block count, ten-second standing/falling result, changed base, and retest result separately. A fall is valid evidence.
    • Worked example: six blocks on a wide base, timer to ten, then move one base block and retest; do not treat tallest as best.
    • Annotated exemplar: point to the same six blocks and the ten-second timer in both drawings; circle the changed base.
    • Finished example: before/after record with six blocks counted, 10 seconds marked, base change circled, and standing/falling results recorded.
    • Adult supervision ratio: one adult can supervise low seated builds with clear tables; add help for children needing construction or counting support.
    • SDS/product gate: SDS not applicable: no chemical product is used; inspect large blocks for damage and use only clean, stable classroom blocks.
    • Print/accessibility check: no printing required; use large blocks, teacher-drawn records, three-block reteach models, and dictated comparisons.
    • Board setup / discussion: six blocks, 10 seconds, before/after boxes. Ask, “What stayed the same? Did your change help this test?”
    • Kit and label text: 20 large blocks, tray/mat, two-attempt sheet. Label: K W5-6 — SIX BLOCK TEST.
    • Cleanup / reset: count all 20 blocks into each tray, flatten sheets into the kit folder, and leave no model above seated height.
    • Unfinished work: keep the first-result sheet and mark the second test pending; do not infer a result from a partner.
    • Misconception / interpretation: height is not the criterion; inspect base width, leaning, slipping, and whether the hand was removed.
    • Reteach: use three blocks and a visibly wide/narrow base, then repeat the ten-second check with the same criterion.
    • Safety classification / supervision: severity: low; likelihood: unlikely. Seated construction only; no throwing, shaking, walking gallery, or furniture climbing.
    • Accessibility / print check: large blocks and teacher-drawn record; offer a three-block model, partner pointing, or dictated comparison.

    Weeks 7–9 — Engineering Helpers¶

    • Student material: plan/result sheet, two empty cups, cardboard, sticks, tape strips, and tray; no-print.
    • Evidence / answer guidance: record requested need, plan, number of cups aboard, one changed part, and before/after result. A decoration is not functional evidence.
    • Worked example: flat tray carries two empty cups across the marked 30 cm path; add one low edge and retest slowly.
    • Annotated exemplar: point to both cups still on the tray at the path endpoint, then circle the added edge as the single changed part.
    • Finished example: plan plus two result marks showing whether two empty cups stayed on the tray before and after one edge change.
    • Adult supervision ratio: one adult can supervise seated teams with pre-cut materials; adult handles cutting and supports tape use as needed.
    • SDS/product gate: The exact masking-tape brand/product remains HOLD in the SDS register until its current manufacturer SDS and school approval are recorded. Use clean cardboard and empty cups, with no liquids or real-person trials.
    • Print/accessibility check: no printing required; provide large pieces, adult scribing, two choices, and child-directed seated roles.
    • Board setup / discussion: helper request, two cups, path, and same / changed. Ask, “Who requested this? What stayed the same?”
    • Kit and label text: two cups, two cardboard squares, ten sticks, ten tape strips, tray. Label: K W7-9 — TWO-CUP TRAY.
    • Cleanup / reset: remove reusable sticks, sort dry cardboard, store models by kit number, and count tape strips only if still usable.
    • Unfinished work: store the model and latest result with the child’s sheet; next meeting begins with a fresh test, not a guessed result.
    • Misconception / interpretation: a classroom tray is not an assistive device; a failed carry is useful test evidence.
    • Reteach: pre-fold a flat tray, offer “edge / no edge,” and let the child direct the slow movement while an adult handles tape.
    • Safety classification / supervision: severity: low; likelihood: unlikely after controls. Seated construction only; an adult cuts cardboard/tape, with no liquids, body-weight, pet, or real-person trials.
    • Accessibility / print check: large pieces, adult scribing, two choices, and seated roles; no printed request or home materials required.

    Week 10 — Bridges Connect Us¶

    • Student material: half-sheet, two supports, cardboard deck, identical large load block, ruler, and tray; no-print.
    • Evidence / answer guidance: identify supports/deck, span the 5 cm gap, hold the same load for three seconds, and compare the changed deck.
    • Worked example: two equal supports, long deck, load at center for three seconds; fold a second deck into a shallow channel and repeat.
    • Annotated exemplar: point to the unchanged gap and load, then circle the folded deck and record “held 3 seconds” or “fell.”
    • Finished example: bridge sketch with two equal supports, a 5 cm gap, the same load, and before/after three-second results.
    • Adult supervision ratio: one adult can supervise seated desk models; adult places or retrieves the load when fingers or stability are concerns.
    • SDS/product gate: SDS not applicable: no chemical product is used; inspect smooth blocks and cardboard, and use only a pretested large classroom load.
    • Print/accessibility check: no printing required; use large parts, visual/tactile labels, and child-directed adult placement.
    • Board setup / discussion: support + gap + deck + load; same gap / same load / changed deck. Ask, “What stayed the same?”
    • Kit and label text: two supports, two deck pieces, one load block, tray, ruler. Label: K W10 — BRIDGE TEST.
    • Cleanup / reset: remove load, count supports/decks, flatten reusable cardboard, return ruler, and leave no load balanced.
    • Unfinished work: record load test pending; next use equal supports and the same load, not a reconstructed claim.
    • Misconception / interpretation: a short plank does not span every gap; a fall means the criterion was not met in that trial.
    • Reteach: demonstrate parts with an unloaded deck, then let the child direct adult placement of one safe load.
    • Safety classification / supervision: severity: moderate; likelihood: unlikely after controls. For the desk model, an adult inspects blocks and places the load; no people, pets, tall supports, or fingers under loads.
    • Accessibility / print check: large parts, visual/tactile labels, and child-directed adult placement; no print or tiny car required.

    Week 11 — Coding Thankfulness¶

    • Student material: gratitude half-sheet, 3-by-3 grid, token, RIGHT/UP/DOWN/STOP cards; no-print.
    • Evidence / answer guidance: child identifies recipient/message, predicts two moves, corrects one wrong card, and explains the resulting path.
    • Worked example: RIGHT, DOWN, STOP misses; reset and replace DOWN with UP. STOP is not a movement.
    • Annotated exemplar: point to the DOWN card as the first mismatch, the missed target, and the replacement UP card.
    • Finished example: gratitude message plus a dated grid showing the wrong route crossed out and the corrected route reaching the recipient.
    • Adult supervision ratio: one adult can supervise seated paper teams; optional ScratchJr requires the regular device supervision used by the classroom.
    • SDS/product gate: SDS not applicable: no chemical product is used; use only an already approved, pretested device extension.
    • Devices/external-service compliance: Optional hardware/software is one school-approved tablet with the installed ScratchJr app and an already-open local project. Do not create an account or upload work. Record software execution only when a child taps the green flag, changes a movement block, and reruns it; otherwise defer execution as not assessed and retain the paper route evidence only.
    • Print/accessibility check: no printing required; use large cards, dictated messages, no public names, and adult movement directed by the child.
    • Board setup / discussion: recipient icon, START, target, ordered cards. Ask, “Which step changed? Did the output match?”
    • Kit and label text: grid, token, four command cards. Label: K W11 — THANKFUL PATH.
    • Cleanup / reset: repack four cards, return tokens to START, retain dated messages, and clear crayons.
    • Unfinished work: preserve the route and message privately; finish the prediction/correction during the next individual check.
    • Misconception / interpretation: motion marks are not executable software; a wrong endpoint is a sequence/orientation issue to debug.
    • Reteach: use two cards and two pictured endpoints, then add STOP after the route is secure.
    • Safety classification / supervision: severity: low; likelihood: unlikely. Seated paper activity only; optional ScratchJr is school-device supervised and never required.
    • Accessibility / print check: large cards, dictated message, no public names, and adult movement directed by the child.

    Week 12 — Making Gifts for Others¶

    • Student material: two sheets, four large paper shapes, crayon, glue stick, and plan/card; no-print.
    • Evidence / answer guidance: child names recipient, explains one purposeful visual choice, and revises a feature to make meaning clearer; polish is not assessed.
    • Worked example: add one large shape to an unclear card and explain how it clarifies the message.
    • Annotated exemplar: point to the added shape and say exactly which part of the recipient’s message it makes easier to understand.
    • Finished example: card with one large purposeful shape circled and a child explanation of how it clarifies the intended message.
    • Adult supervision ratio: one adult can supervise seated art teams; adult retains control of scissors and supports glue use.
    • SDS/product gate: The exact school glue-stick brand/product remains HOLD in the SDS register until its current manufacturer SDS and school approval are recorded. Use precut shapes, with no glitter, food, or tiny stickers.
    • Print/accessibility check: no printing required; offer large high-contrast shapes, ready-folded cards, scribing, and no handwriting requirement.
    • Board setup / discussion: recipient icon → plan → card → “clearer.” Ask, “What message will it carry?”
    • Kit and label text: two sheets, four shapes, glue stick, crayon. Label: K W12 — MESSAGE CARD.
    • Cleanup / reset: cap glue, count shapes, retain cards, recycle clean scraps, and return scissors to adult storage.
    • Unfinished work: save the plan and card flat; finish the explanation/revision without requiring delivery.
    • Misconception / interpretation: more decoration is not clearer communication; ask the child to point to the intended meaning.
    • Reteach: offer two large shapes and a ready-folded card, then model one purposeful placement.
    • Safety classification / supervision: severity: low; likelihood: unlikely after controls. Seated art only; an adult uses scissors, with no glitter, food, tiny stickers, or unapproved delivery.
    • Accessibility / print check: large shapes, high contrast, ready-folded card, scribing, and no handwriting requirement.

    Week 13 — Fall Celebration¶

    • Student material: dated evidence sheet, crayon, or fresh 3-by-3 grid/token/card route; no-print.
    • Evidence / answer guidance: child shows one actual result, explains what it demonstrates, and names one practice need; a favorite activity is not evidence.
    • Worked example: show RIGHT, UP, STOP from START and say, “This shows I corrected the path,” with today’s date if fresh.
    • Annotated exemplar: point to the dated route and the final target square; name only the skill that this result demonstrates.
    • Finished example: one dated evidence sheet with a visible result, one accurate claim, and one next-practice note.
    • Adult supervision ratio: one adult can supervise concurrent seated demonstrations; optional documentation needs the classroom’s normal consent-aware adult handling.
    • SDS/product gate: SDS not applicable: no chemical product, treats, or purchased celebration material is required; use only the paper route and existing work.
    • Devices/external-service compliance: Optional hardware is the school-approved documentation camera named in the local media process; no external service or upload is part of the lesson. If consent or the approved camera is unavailable, defer photography and retain the dated paper route/work as the evidence; a photograph never substitutes for the demonstrated skill.
    • Print/accessibility check: no printing required; accept oral, gesture, drawing, pointing, and a private fresh route instead of public presentation.
    • Board setup / discussion: claim → evidence → next practice; ask, “What can you show me, and what does it show?”
    • Kit and label text: grid, token, RIGHT/UP/STOP cards, evidence sheet. Label: K W13 — SHOW THE EVIDENCE.
    • Cleanup / reset: retain dated sheets, return cards/tokens/crayons, and leave no food or certificate materials.
    • Unfinished work: use the fresh route next time and label it today; never backdate or invent portfolio evidence.
    • Misconception / interpretation: attendance or a partner’s success does not prove mastery; record prompted/not yet honestly.
    • Reteach: model one claim with one visible result, then ask the child to point to the matching evidence.
    • Safety classification / supervision: severity: low; likelihood: unlikely. Seated reflection only; optional camera use follows existing school consent and privacy practice.
    • Accessibility / print check: oral, gesture, drawing, and fresh paper route accepted; no presentation queue or public display required.

    Weeks 14–15 — Light All Around¶

    • Student material: three large material squares, secured flashlight, fixed screen, tissue art squares, frame, tape, and record sheet; no-print.
    • Evidence / answer guidance: child classifies actual result (clear/fuzzy/blocked), identifies a kept-same condition, and explains a tissue placement choice.
    • Worked example: fixed lamp/material/screen positions; clear plastic transmits more, tissue scatters some, cardboard blocks in this test.
    • Annotated exemplar: point to the fixed distance marks first, then point to the screen result for each material without calling tissue a light source.
    • Finished example: comparison record with fixed positions, three material outcomes, and one tissue-art placement linked to the observed result.
    • Adult supervision ratio: one adult can supervise seated comparisons; adult handles batteries and any flashlight adjustment.
    • SDS/product gate: The exact masking-tape brand/product remains HOLD in the SDS register until its current manufacturer SDS and school approval are recorded. Intact flashlight hardware needs no lesson SDS; remove damaged or leaking batteries from service.
    • Print/accessibility check: no printing required; use high-contrast/tactile samples, child-directed placement, and no circuit or screen requirement.
    • Board setup / discussion: source → material → screen and same distance / changed material. Ask, “What did the test show?”
    • Kit and label text: secured flashlight, plastic, tissue, cardboard, white screen. Label: K W14-15 — LIGHT TEST.
    • Cleanup / reset: switch off lights, count three squares, remove dry tape, store batteries closed, and retain first results.
    • Unfinished work: mark comparison or art explanation pending; rerun only with fixed positions and record a fresh result.
    • Misconception / interpretation: tissue is not a light source; a surprising result may indicate changed distance or room light.
    • Reteach: compare two materials at one marked distance, using clear/fuzzy/blocked cards and child-directed placement.
    • Safety classification / supervision: severity: moderate; likelihood: unlikely after controls. During the supervised light demonstration, an adult handles batteries; no Sun viewing, lasers, flames, glass, or beams at eyes.
    • Accessibility / print check: high-contrast samples, tactile material differences, adult placement directed by child, and no circuit or print packet.

    Week 16 — Star of Wonder¶

    • Student material: five-dot model card, paper, crayon; no-print.
    • Evidence / answer guidance: child counts 3–5 dots accurately, makes a recognizable pattern, and states one model limit.
    • Worked example: five separated dots connected as a zigzag; say, “This picture does not show real distance or make light.”
    • Annotated exemplar: point to five counted dots as the model evidence, then point outside the drawing to show the missing real distance.
    • Finished example: drawing with three to five counted dots and a sentence or gesture that it is a model, not a light-producing star.
    • Adult supervision ratio: one adult can supervise the seated paper activity and individual counting checks.
    • SDS/product gate: SDS not applicable: no chemical product or purchased astronomy material is required; use teacher-drawn cards only.
    • Print/accessibility check: no printing required; provide raised dots, large spacing, oral counting, and ordinary paper.
    • Board setup / discussion: five dots, count marks, model ≠ real sky. Ask, “What is real in the sky? What can this picture not tell us?”
    • Kit and label text: five-dot model card, sheet, crayon. Label: K W16 — STAR MODEL.
    • Cleanup / reset: collect dated drawings, return cards/crayons, and leave no dark-room or night-observation setup.
    • Unfinished work: retain the model and finish counting/limit explanation at the next check.
    • Misconception / interpretation: pointed paper stars are symbols, not the physical shape of stars; accept the symbol then clarify.
    • Reteach: use three large tactile dots, count together, and contrast one paper mark with a teacher description of a real star.
    • Safety classification / supervision: severity: low; likelihood: unlikely. Seated drawing only; no Sun viewing, dark-room work, or night outing.
    • Accessibility / print check: raised dots, large spacing, oral counting, and teacher-drawn cards; no stickers or glitter.

    Week 18 — New Year Goals¶

    • Student material: dated sky-record sheet, three large weather symbols, and crayon; no-print.
    • Evidence / answer guidance: record today’s observed cloud coverage, distinguish observation from prediction, and choose a repeat-and-compare goal.
    • Worked example: date/time partly cloudy, circle matching symbol, and draw “record again and compare.”
    • Annotated exemplar: point to the date/time as when the observation happened and the repeat arrow as a future check, not today’s fact.
    • Finished example: dated sky record with one matching cloud symbol and a drawn “record again and compare” goal.
    • Adult supervision ratio: one adult can supervise the indoor window/report pathway; no outdoor staffing is needed for the minimum lesson.
    • SDS/product gate: SDS not applicable: no chemical product or special weather device is required; use teacher-labeled observation/model data when the sky cannot be viewed.
    • Print/accessibility check: no printing required; use large/tactile symbols, teacher report, dictation, and a window-free indoor option.
    • Board setup / discussion: eye → dated symbol → repeat arrow. Ask, “What did you observe, and how will you check it again?”
    • Kit and label text: clear/partly/cloud-covered symbols, record sheet, crayon. Label: K W18 — SKY RECORD.
    • Cleanup / reset: store records for Week 20, return symbols/crayons, and reset the window-free indoor route.
    • Unfinished work: label teacher/model data clearly and defer actual-weather evidence; do not assign home observation.
    • Misconception / interpretation: a sunny drawing does not prove warmth; ask what was actually visible or reported.
    • Reteach: offer two symbols and a teacher-labeled observation, then model date/time and a repeat goal.
    • Safety classification / supervision: severity: low; likelihood: unlikely. Indoor observation only; no Sun viewing, climbing, outdoor exposure, or forced sensory task.
    • Accessibility / print check: tactile/large symbols, teacher report labeled as such, dictation, and no-print alternative.

    Weeks 19–22 — Exploration Stations¶

    • Student material: use one whole-class challenge per meeting: six-block retest, two dated sky records, six-shape repeat, or grid/token/cards; no-print.
    • Evidence / answer guidance: keep four separate checks: structure change/result, weather comparison, pattern extension, and route correction. A station stamp is not evidence.
    • Worked example: board each meeting’s minimal model: same six blocks, dated symbol pair, AB repeat, or RIGHT, DOWN corrected to RIGHT, UP.
    • Annotated exemplar: point to the current meeting’s matching evidence line only; do not use participation at another meeting as proof.
    • Finished example: four dated evidence marks, one for each meeting challenge, with the current result and any prompt level identified.
    • Adult supervision ratio: one adult can supervise the single whole-class seated challenge; optional robot work remains a separate adult-controlled station.
    • SDS/product gate: SDS not applicable to the listed paper, blocks, shapes, or intact optional Sphero/tablet hardware; inspect all items and remove damaged or leaking batteries from service.
    • Devices/external-service compliance: Optional hardware is the previously approved Sphero, paired tablet, and installed Sphero Edu Drive interface from Weeks 2-3. Do not create a student account or upload data. Record hardware execution only for a child's actual drive-and-stop turn; otherwise defer H as not assessed and keep the four named paper challenge records.
    • Print/accessibility check: no printing required; use large tactile shapes, scribing, indoor no-device routes, and no station passport.
    • Board setup / discussion: write the current meeting number and same / changed / result; ask, “What did this test or record actually show?”
    • Kit and label text: meeting-specific kits from the lesson quantities. Labels: K W19 — RETEST, K W20 — SKY RECORD, K W21 — REPEAT, K W22 — DEBUG.
    • Cleanup / reset: end one challenge before setting up the next; count blocks/shapes/cards, save dated records, and reset START.
    • Unfinished work: carry only the current evidence sheet forward; if prior weather is missing, make and label fresh records.
    • Misconception / interpretation: participation at a station does not prove transfer; interpret each missing check separately.
    • Reteach: isolate the relevant challenge with two choices, one repeated test, or adult-directed token movement.
    • Safety classification / supervision: severity: moderate; likelihood: unlikely after controls. Seated paper/structure work is the core pathway; an optional robot remains a separate adult-controlled extension.
    • Accessibility / print check: large tactile shapes, scribing, indoor no-device route, and no five-station rotation or passport.

    Week 23 — Catholic Schools Week¶

    • Student material: display/evidence sheet, fresh grid/token/cards if needed, and two hypothetical sharing cards; no-print.
    • Evidence / answer guidance: child identifies actual result, explains a limit, revises for an audience, and distinguishes private from shareable information.
    • Worked example: fresh RIGHT, UP, STOP dated today; use a house icon instead of any real address.
    • Annotated exemplar: point to the dated route as shareable learning evidence and the fictional house icon as the privacy-safe substitute.
    • Finished example: anonymous display sheet with one dated result, a clear explanation, one revision, and a fictional house icon.
    • Adult supervision ratio: one adult can supervise seated preparation and partner sharing; public display or photography uses the school’s existing adult process.
    • SDS/product gate: SDS not applicable: no chemical product or visitor/device purchase is required; use only approved classroom display materials.
    • Devices/external-service compliance: Optional hardware is the school-approved documentation camera named in the local media process; no external service or upload is part of the lesson. If approval or consent is absent, defer photography and retain the dated evidence sheet or fresh paper route; the image is documentation, not skill evidence.
    • Print/accessibility check: no printing required; use large icons, anonymous examples, pointing/dictation, and no public-speaking requirement.
    • Board setup / discussion: evidence → explanation → revision; privacy shield beside fictional house icon. Ask, “Did you do, observe, or predict this?”
    • Kit and label text: grid, token, RIGHT/UP/STOP cards, evidence sheet. Label: K W23 — SHARE SAFELY.
    • Cleanup / reset: save sheets in the approved class envelope/display area, remove names from practice examples, and repack kits.
    • Unfinished work: keep the individual sheet; do not send children home for missing photographs or portfolios.
    • Misconception / interpretation: a favorite photo or prayer does not prove a science/skill claim; ask for the visible result.
    • Reteach: model one evidence sentence and one privacy choice with the fictional cards.
    • Safety classification / supervision: severity: low; likelihood: unlikely. Seated communication only; public display, images, and visitors require existing school processes.
    • Accessibility / print check: pointing/dictation, large icons, anonymous examples, and no technology or public-speaking requirement.

    Weeks 24–25 — Dash Robot Friends¶

    • Student material: 4-by-2 paper grid, paper Dash, five large command cards, kindness card; no-print.
    • Evidence / answer guidance: child plans three steps, predicts endpoint, corrects one wrong step, and communicates a respectful message. Real programming/operation is separate evidence.
    • Worked example: RIGHT, RIGHT, DOWN misses FRIEND; replace DOWN with UP and retest from the same START.
    • Annotated exemplar: point to the same START, identify DOWN as the wrong third command, and point to FRIEND after the corrected retest.
    • Finished example: three-card paper route reaches FRIEND after DOWN is replaced with UP, with the kindness card beside the target.
    • Adult supervision ratio: one adult can supervise seated paper teams; any Dash run requires one adult controlling the clear lane and stop function.
    • SDS/product gate: The exact painter's tape brand/product remains HOLD in the SDS register until its current manufacturer SDS and school approval are recorded. Intact Dash/tablet hardware needs no lesson SDS; remove damaged or leaking batteries from service.
    • Devices/external-service compliance: Optional hardware/software is one school-approved Dash, its paired tablet, and the installed Make Wonder Blockly app/interface. Do not create a student account or upload data. Record P only when a child edits and runs the tested block sequence and H only for actual safe control; otherwise defer both as not assessed and retain the paper route evidence.
    • Print/accessibility check: no printing required; use the complete paper route, large cards, seated roles, and no tiny tokens.
    • Board setup / discussion: START, FRIEND, three-step route, input/output, and same start. Ask, “What changed? What stayed the same?”
    • Kit and label text: grid, paper Dash, two RIGHT, UP, DOWN, STOP. Label: K W24-25 — DASH PAPER PATH.
    • Cleanup / reset: return five cards, place paper Dash at START, retain kindness cards, stop/store optional hardware, and count kits.
    • Unfinished work: save the route and card; resume at the same START with paper evidence before any hardware extension.
    • Misconception / interpretation: Dash does not decide what is kind; missed target prompts checks of heading, distance, surface, connection, and code.
    • Reteach: begin with two cards and one pictured endpoint, then add the third step after reset behavior is secure.
    • Safety classification / supervision: severity: moderate; likelihood: unlikely after controls. Optional Dash is adult-controlled equipment in a clear lane; no racing, chasing, free driving, or physical delivery.
    • Accessibility / print check: paper route is complete lesson, with large cards, seated roles, no tiny tokens, and child-directed adult movement.

    Weeks 26–27 — Helping Hands Engineering¶

    • Student material: plan/result sheet, folded paper book, cardboard, sticks, tape, tray, and large drawn picture; no-print.
    • Evidence / answer guidance: record both criteria: stand ten seconds and picture remains visible; compare before/after and name a tradeoff.
    • Worked example: low front support holds book but may hide the circle; change one feature and retest both criteria.
    • Annotated exemplar: point to the standing book and visible circle separately, then circle the support change that helped one criterion and affected the other.
    • Finished example: before/after record showing ten-second standing and picture visibility, with one support change circled as a tradeoff.
    • Adult supervision ratio: one adult can supervise seated construction with pre-cut materials; adult handles scissors and supports tape use.
    • SDS/product gate: The exact masking-tape brand/product remains HOLD in the SDS register until its current manufacturer SDS and school approval are recorded. Use clean cardboard and a paper book model only, never a real assistive-device trial.
    • Print/accessibility check: no printing required; use a large book/picture, adult scribing, and child-directed tests.
    • Board setup / discussion: reader request, 10 seconds, visible picture, and helps / makes harder. Ask, “What did the reader request?”
    • Kit and label text: two cardboard squares, folded paper book, ten sticks, ten tape strips, tray. Label: K W26-27 — BOOK STAND.
    • Cleanup / reset: store dry models by kit, reclaim sticks, sort cardboard, and remove reusable tape scraps.
    • Unfinished work: keep actual first-test record and mark the second criterion pending; never infer success.
    • Misconception / interpretation: this is a classroom model, not an approved assistive device; a tradeoff is not a personal deficit.
    • Reteach: use a pre-folded stand and two choices, then test standing and visibility separately.
    • Safety classification / supervision: severity: low; likelihood: unlikely after controls. Seated construction only; adult scissors/tape management, with no body-weight, pet, infant, wearable, or real-person trial.
    • Accessibility / print check: large book/picture, adult scribing, child-directed testing, and no print or home supplies.

    Week 28 — Circles and Pi¶

    • Student material: large paper circles/squares, teacher-held ball, paper strip, and crayon; no-print.
    • Evidence / answer guidance: child distinguishes flat circle, square, and solid ball, then extends circle-square AB by two shapes.
    • Worked example: trace circle, count square corners, arrange circle-square-circle-square, predict circle-square.
    • Annotated exemplar: point to the flat circle boundary, touch each of the square’s four corners, and point to the repeated AB unit.
    • Finished example: sorted circle/square/ball demonstration plus a paper strip extending circle-square twice.
    • Adult supervision ratio: one adult can supervise the seated shape sort and carry the teacher-held ball between tables.
    • SDS/product gate: SDS not applicable: no chemical product is used; use large precut paper shapes and a clean classroom ball, with no food, coins, or string.
    • Print/accessibility check: no printing required; use large or raised shapes, placement instead of drawing, and no pi calculation.
    • Board setup / discussion: flat circle vs solid ball, AB repeat, and zero/four corners. Ask, “What is flat? What repeats?”
    • Kit and label text: three circles, three squares, strip, crayon. Label: K W28 — SHAPES / REPEAT.
    • Cleanup / reset: count six shapes into each kit, collect strips/crayons, and return the teacher-held ball.
    • Unfinished work: save the strip and complete the next two shapes at the next seated check.
    • Misconception / interpretation: anything round is not a circle; compare flat tracing with the solid ball. Pi is adult context only.
    • Reteach: sort two shapes at a time, use raised outlines, and extend a two-item AB repeat.
    • Safety classification / supervision: severity: low; likelihood: unlikely. Seated shape work only; the teacher holds the ball, with no rolling races, food, coins, yarn, or Sun viewing.
    • Accessibility / print check: large/high-contrast or raised shapes, placement instead of drawing, and no radius/pi calculation.

    Weeks 29–31 — Growing Things¶

    • Student material: enclosed adult-managed seed cup, dated observation sheet, large plant-part cards, crayon; no-print.
    • Evidence / answer guidance: child records visible change (for example root/shoot/height category), compares dates, and names one care action. Do not claim growth without a dated observation.
    • Worked example: dated cup drawing: Day 1—seed, Day 2—small shoot; use a teacher ruler/category only if already in the lesson.
    • Annotated exemplar: point to the two dates and circle the visible shoot; do not fill an undated gap from memory.
    • Finished example: two dated seed-cup drawings with the visible shoot circled and one care action recorded.
    • Adult supervision ratio: one adult can supervise the teacher-managed enclosed seed tray; add adult help for any individual observation or spill response.
    • SDS/product gate: SDS not applicable: no chemical, fertilizer, or soil is used; keep untreated-seed cups enclosed and adult-managed, with no tasting, opening, soil handling, or unsupervised watering.
    • Print/accessibility check: no printing required; use large plant-part cards, tactile/visual alternatives, and dictation.
    • Board setup / discussion: seed → root/shoot → plant, date arrows, and seen / cared for. Ask, “What changed since the last record?”
    • Kit and label text: enclosed seed cup, observation sheets, plant-part cards. Label: K W29-31 — GROWTH RECORD.
    • Cleanup / reset: keep cups enclosed on a stable teacher-managed tray, wipe spills, return cards, and file records by date.
    • Unfinished work: label the last actual date and continue at the next meeting; do not fill missing days from memory.
    • Misconception / interpretation: a taller drawing is not proof of growth; inspect dates, viewpoint, and whether the cup was disturbed.
    • Reteach: compare two teacher-labeled drawings and have the child point to one visible difference and one care action.
    • Safety classification / supervision: severity: moderate; likelihood: unlikely after controls. The adult manages enclosed biological material; no tasting, opening seed cups, soil handling, or unsupervised watering.
    • Accessibility / print check: large plant-part cards, tactile/visual alternatives, dictation, and enclosed no-print setup.

    Week 33 — New Life Engineering¶

    • Student material: life-cycle picture cards, paper model sheet, large paper shapes, crayon, and glue only if already supplied; no-print.
    • Evidence / answer guidance: child orders the pictured stages, identifies one change, and explains that a paper model represents rather than creates life.
    • Worked example: place three teacher-selected stages in order, circle the changed feature, and add one large shape to the model.
    • Annotated exemplar: point to the arrows between stages and circle the pictured change; identify the paper model as a representation, not living material.
    • Finished example: three ordered life-cycle cards with one visible change circled and a paper model labeled as a representation.
    • Adult supervision ratio: one adult can supervise the seated card/model activity and any glue use; no live-organism handling is needed.
    • SDS/product gate: If glue is used, its exact brand/product remains HOLD in the SDS register until its current manufacturer SDS and school approval are recorded. No live specimen is required, and the no-glue paper placement remains available.
    • Print/accessibility check: no printing required; use large high-contrast/tactile cards, placement, dictation, and teacher-drawn alternatives.
    • Board setup / discussion: before → change → after, model boundary, and care icon. Ask, “What changed, and what does this model leave out?”
    • Kit and label text: stage cards, model sheet, large shapes, crayon. Label: K W33 — NEW LIFE MODEL.
    • Cleanup / reset: collect cards by stage set, retain dated models flat, cap glue, and recycle clean scraps.
    • Unfinished work: preserve the ordered cards/model and finish the explanation later; do not require a real organism or home specimen.
    • Misconception / interpretation: a model does not cause life or prove every unseen stage; ask for the pictured evidence.
    • Reteach: use two stages first, then add the third and ask “before/after” with gestures.
    • Safety classification / supervision: severity: low; likelihood: unlikely after controls. Seated paper model only; no live animal handling, unknown specimens, tasting, or scissors by children.
    • Accessibility / print check: large high-contrast/tactile cards, placement/dictation, and teacher-drawn alternatives.

    Week 34 — Year Celebration¶

    • Student material: evidence/celebration sheet, selected dated work, crayon, and one familiar paper challenge; no-print.
    • Evidence / answer guidance: child demonstrates one current skill, points to evidence, names one next practice, and distinguishes memory from today’s demonstration.
    • Worked example: show a dated structure/path/growth record and say one accurate claim plus one limit.
    • Annotated exemplar: point to the dated result that supports the claim, then point to a blank/unknown feature as the limit.
    • Finished example: one selected dated work sample with an accurate claim, visible supporting evidence, and one next-practice statement.
    • Adult supervision ratio: one adult can supervise concurrent seated demonstrations and partner sharing; private individual checks remain available.
    • SDS/product gate: SDS not applicable: no chemical product, food, certificate, or device is required; use familiar paper materials already in the lesson.
    • Devices/external-service compliance: Optional hardware is the school-approved documentation camera named in the local media process; no external service or upload is part of the lesson. If approval or consent is absent, defer photography and retain the dated paper demonstration/work; a photograph does not establish year-long growth.
    • Print/accessibility check: no printing required; accept oral, gesture, drawing, pointing, private sharing, and a fresh dated demonstration.
    • Board setup / discussion: I can show… / This evidence tells… / Next I will practice…. Ask, “What can you show today?”
    • Kit and label text: evidence sheet, familiar paper challenge materials, crayon. Label: K W34 — CELEBRATE / PRACTICE.
    • Cleanup / reset: return shared materials, file selected work, clear display surfaces, and leave no required celebration supplies.
    • Unfinished work: collect a fresh dated demonstration next meeting; do not backfill a missing year-long record.
    • Misconception / interpretation: attractive work or attendance is not proof of the objective; record the demonstrated component only.
    • Reteach: choose the simplest familiar paper pathway and model claim/evidence/next-step with one child.
    • Safety classification / supervision: severity: low; likelihood: unlikely. Seated reflection and demonstration only; no food, public posting, or device required.
    • Accessibility / print check: oral/gesture/drawing/pointing accepted, private class sharing available, and no-print evidence sheet.
