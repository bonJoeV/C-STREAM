    Completion checks and seven classroom simulations¶

    Review/completion work: October 4, 2026. Evidence is document inspection, source verification, arithmetic and desk walkthroughs. No actual classroom, substitute-arrival, physical-kit or student-outcome trial was performed.

    Simulation Concrete written pathway and correction Desk result and remaining local check

    Changes made to improve the lesson-pathway backlog¶

    1. Rebuilt all remaining Grades 1-6 lesson pathways, preserving earlier references and the updated Snap routes; the separate artifact audit now prevents these revisions from being mislabeled classroom-ready.
    2. Added actual individual checks, worked/fictional data and scientific/model limits; removed withdrawn unsafe paths and unsupported heritage quotations.
    3. Preserved realistic periods and includes cleanup, setup, trial/role plans, scalable supplies, troubleshooting and younger/older grade expectations.
    4. Reconciled material names without pretending software, a saved record, a module or reported holding is an independently verified purchase.
    5. Added exact external-candidate validation and a frozen baseline ledger.
    6. Moved map regression, all-grade reference, budget, K, Snap and source-map checks into publication CI; pull requests validate/build without deployment.
    7. Explicitly excluded the documentation-root developer README from publication, resolving the earlier README/index conflict so the build can run strictly.

    Remaining work is school-controlled release evidence¶

    The teacher artifact readiness review records complete repository artifact coverage for all 251 lessons. The school release checklist still requires actual counts/condition, model/manual/power checks, source/policy approval, individual accommodations, physical kit locations and classroom pilots. Source access limitations are recorded, not "fixed" by unsupported official claims.

    Before asserting uniformly classroom-ready delivery, pilot selected lessons, time actual preparation/cleanup and collect individual evidence at the local checkpoints. A full document or a passing schema cannot perform those checks. Unresolved unsafe conditions hold the affected pathway; a changed fallback records changed/deferred objectives.
